# E1 主集严格三折冻结基线最终报告：146 实验

日期：2026-11-26 ｜ 数据版本：`e0-v2-id90-strict3train-main` ｜ 主集：73 RBP × 双细胞系 = 146 实验

> 本报告只使用 `e1_main_strict3train_p20_v2` 新训练、合并和统计产物。旧 E1 主集报告继续撤回验收，旧数字仅在 §7 作敏感性审计，不参与模型、超参或结论选择。

## 1. 验收结论与证据边界

**strict3train 主集验收通过。** 15 个 modern run（5 fold × 3 seed）与 5 个 kNN 均完成，独立 AUDIT、五折合并、CV、10,000 次配对 bootstrap、低同源三 seed 和独立回算全部完成。

在当前协议下，**frozen RNA-FM BCE 现代头相对簇去重余弦 kNN，在双轨、head/mid/tail 的 AUROC 与 AUPRC 均更高**。12 个切片的配对 bootstrap 差值均为正、95% CI 均排除 0，双侧有限样本校正 p 均为 0.00019998。尾部 pooled ΔAUROC 为 neg1c +0.031365、neg2 +0.024114，ΔAUPRC 分别为 +0.043649、+0.034854。

结论仅适用于这两个既定基线的比较，不支持“完整最强基线胜利”“SOTA”、其他骨干/微调方案或机制因果主张。三个训练 seed 是统计重复，不是独立生物重复。

## 2. 冻结协议

- 每折 test 为 `f`，validation 为 `(f+1) mod 5`；train **只含其余三个显式 fold**。正例和负例均不用补集条件，`fold=-1` 不进入任何 CV train；val/test 与冻结原始划分保持一致。
- modern：冻结 RNA-FM 640 维均值嵌入、256 隐层 MLP、BCE、AdamW、label smoothing 0.02。逐任务按 validation AUPRC 早停，`patience=20`、`min_delta=1e-4`，1000 epoch 仅作故障保险；恢复并保存最佳 checkpoint。旧 30 点网格/两遍重训不是本协议。
- kNN：训练正例按冻结 id90 簇保留一个代表，负例不变；余弦距离，`k∈{5,10,20}` 由尾部 RBP validation 宏 AUPRC 选择。五折双轨均选 k=20。
- neg2 有放回重复窗口保留，以 `experiment/fold/track/window_id/label/occurrence` 对齐三 seed 与 kNN。
- bootstrap：先池化同一实验五折 test 预测，再在实验内逐窗配对重采样 10,000 次；先对三 seed 指标取均值，再对实验宏平均。区间为 percentile 95% CI，双侧符号 p 含有限样本校正。

## 3. 完整性与协议验收

- 所有 run 均有显式 `cuda:0` 数值探针；严格三折 train ID/折计数通过，未分配 fold=-1 未进入 train。
- 五折 test 行数为 1,778,203 / 1,728,417 / 1,728,904 / 1,728,190 / 1,728,945。合并后每个 modern seed 与 kNN 均为 **8,692,659 行**；原始 split、标签、tier、track、窗口 ID 和 occurrence 全部对齐，预测分数有限。
