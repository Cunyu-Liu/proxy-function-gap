## 2. 划分协议（§4.7）

- 单元：GENCODE v42 BASIC 同链合并区域（51,042 个）。
- 主划分：CD-HIT-EST **90% identity** 聚类正例窗口（主集 146 实验；参数 `-c 0.9 -n 8 -G 1 -g 1 -d 0`，
  等长 101nt 窗口全局 identity 模式）→ 同簇窗口所在区域 union
  + 101nt 窗口跨区链接 → 连通分量整块分配到 5 折（**窗口负载**贪心均衡，seed=20261122）。
- 敏感性：80% identity 重聚类备用划分（仅敏感性分析，不作主数字）。
- 用法：5 折 CV；每 run test=fold k，val=fold (k+1)%5，train=其余 3 折。
  val 用于早停（指标=验证集尾部 AUPRC）与路由校准；**test 每配置只跑一次最终数字**。
- 冻结产物：region_fold_map.id90.tsv、fold-{k}.regions.id90.bed、split_manifest.id90.json
  （**已冻结 2026-11-22T06:30:55Z**；manifest sha256=3e1e056800f34062c34c631c1c7b9e29380cf0f9621d377f5dec525557b00e18；
  2,168,739 窗口→1,117,660 簇→48,981 分量；各折窗口 [439609, 426928, 426928, 426927, 426927]）。
- 与 bbad307 的偏差（全部记录于 manifest）：原管线无种子随机 shuffle+轮转分折（不可复现）、
  无聚类叠加；本协议固定种子+簇独占（执行文档要求）。
- 低同源分桶（**边界冻结**）：每测试正例窗口到同折训练正例的最近邻 identity
  （冻结 RNA-FM 嵌入余弦 top1 检索 → 精确全局比对复核；比对参数 match=1/mismatch=-1/
  gap open=-2/extend=-1，identity=匹配碱基数/较长序列长度）。全量产出 per_window_identity.tsv。
  评估桶：[<0.60, 0.60–0.70, 0.70–0.80, 0.80–0.90, 0.90–0.95, ≥0.95]；
  泄漏审计桶（§4.5 表）：[<0.8, 0.8–0.9, 0.9–0.95, 0.95–1.0]。
  **E0 实测分布（n=2,147,319，均值 0.6015）**：<0.60=1,156,219(53.8%) / 0.60–0.70=878,157(40.9%) /
  0.70–0.80=89,905(4.19%) / 0.80–0.90=22,647(1.05%) / 0.90–0.95=386(0.018%) / ≥0.95=5(0.0002%)。
  94.7% 测试窗 d_hom<0.70——低同源尾桶（<0.60）为真实硬切片。
- OOD 套件（全部预注册）：
  1. 跨细胞系：K562→HepG2 与反向（73 双系 RBP；训练只用源系，测试用目标系同 RBP）。
  2. 跨协议：PAR-CLIP→eCLIP（17 RBP；**E0 决定：GRCh37 峰 liftover→hg38**，chain 已备，
     与 eCLIP 同参考基因组/注释；liftover 工具链 E0 第二周安装，失败位点计数记录）。
  3. 整 RBP 留出：训练未见该 RBP 任何峰 → 拒识/未知检测。
  4. 家族整组留出：RBP 按结合 motif 相似性聚类——**方法冻结**：正例窗口 4-mer 组成谱
     （每实验采样 ≤5000 窗口，seed=20261122）→ RBP 级平均谱余弦距离 → 平均链接层次聚类 →
     候选阈值网格 0.05–0.625（步长 0.025）上 silhouette 最优切点。组成谱为 motif 相似性代理，
     motif 级精化留 E1 对照。
     **【已冻结 2026-11-22，run E0-rbp-family-freeze】阈值 0.375，silhouette 0.6396，
     73 RBP → 2 家族（家族1=72 RBP；家族2=HNRNPC 单例）。**
     **局限（如实记录，不改冻结方法）**：4-mer 组成代理区分度弱——72 个 RBP 组成谱相近
     （成对余弦距离中位 0.107，89.6% 对 <0.375），仅分离出 poly-U 结合蛋白 HNRNPC。
     故"家族整组留出"按本冻结退化为≈单独留出 HNRNPC，**不作为主 far-OOD 证据**；
     主 far-OOD 押注**整 RBP 留出（73 个 leave-one-RBP-out）+ 跨细胞系 + 跨协议**。
     motif 级精化（MEME/已知家族注释）留 E1，若与本冻结不一致以本冻结为准并记录差异。
  5. 时间留出：蛋白 E6 用 CAFA 式 t0→t1。

## 3. 负例三轨（E0 审计发现驱动）

**审计发现**：原管线 `bedtools subtract -s -u -wa` 实测返回原始全区间（no-op），
neg-1 排除步骤失效，负例可落在正例 ±300nt 邻域内；neg-2 采样 `random.choices` 无种子。
量化：neg1f 落入 ±300nt 正例邻域比例 **均值 1.82%（中位 1.81%，最大 5.43%）**；
到最近正例 ≤100nt 比例均值 0.71%（neg_audit.tsv，已冻结）。

| 轨 | 定义 | 用途 |
|---|---|---|
| neg1f | 忠实复现（无有效排除），seed=42 | 与 bbad307 文献数字对照 |
| neg1c | 修正版：真 subtract ±300nt 后采样，seed=42 | **主报告轨之一**（干净 bias-agnostic） |
| neg2 | 其他 RBP（排除同 RBP 双系）交联位点，去与本 RBP 1bp 正例重叠，1:1 有放回，random.Random(42) | **主报告轨之二**（bias-aware） |

- 采样帧：含正例（±300nt 扩展）的 BASIC 合并区域（忠实原管线）；1:1 平衡。
- 双轨必报：neg1c 与 neg2；neg1f 仅作对照。neg1c→neg2 降幅 = 技术偏差可学性指标
  （文献参照 0.045–0.085）。
- 窗口：交联位点 ±50nt → 101nt；负链反向互补；T→U；非 ACGU 跳过（计数记录）。

## 4. 评测切片与指标

**T1 切片（胜利判据定义域）**：尾部 RBP（峰数/n_eff 三分桶之尾桶）、低同源（identity 尾桶）、
跨细胞系（73 RBP 双向）、OOD 拒识（整 RBP 留出）。
**T2 切片**：跨协议（17 RBP）、家族留出、头部（代价约束域）。
指标：AUROC/AUPRC（每切片）；worst-group（细胞系×协议×频率组）；
拒识：AUROC-OOD、FPR95、risk-coverage/AURC、precision@coverage、unknown recall；
校准：ECE、Brier（温度缩放前后）。
每消融必报四面板：头部/尾部/低同源/OOD。

## 5. 统计与搜索纪律

- 主对照 3 种子，最终数字 5 种子；配对 bootstrap（按窗口重采样，10,000 次）p<0.05。
- 每 run 记录 run_id/配置/种子/数据版本/指标/wall_seconds 至 experiments.jsonl；主张必须对应 run ID。
- 搜索预算：pilot（20 RBP × 2 系 = 40 实验，**实测 603,245 正例窗口**，pos+neg1c+neg2 ≈ 1.81M）
  successive halving ≤60 run；主集晋级配置 ≤3/阶段，主集搜索 ≤20 run。
- 编码器：RNA-FM / RiNALMo（冻结/LoRA/全参三档）；禁自研预训练；损失 ≤4 项；
  REx/Fishr/自监督双分支/本体原型记忆默认不启用。
- LoRA：r∈{4,8,16} 挂 k/v（E0 基准用 q/k/v，E1 起按 §4.9 挂 k/v）；α=2r；dropout∈{0,0.1}。
- 早停指标=验证集尾部 AUPRC；batch 256–512；epoch 3–5。

## 6. 必跑对照

- **OverfitNN**（最近邻标签平均）：每个 split × 每负例轨必跑；特征=冻结 FM 嵌入 kNN
  与 k-mer 两版；k∈{5,10,20}（簇去重后）。
- 冻结探针（RNA-FM/RiNALMo + 线性头）：E0 内每 split 跑通，作为 G0 的"最强模型"参照之一。
- 文献锚点（协议匹配时复用）：bbad307 11 方法 neg1f/neg2 平均 AUROC（表见执行文档 §4.8）。

## 7. 胜利判据与止损门（§8/§5）

**胜利**：≥2 个 T1 切片对最强基线（FM 微调+logit adjustment+现代配方+检索+离散路由）
统计显著增益（≥3 种子配对 bootstrap p<0.05）；头部代价 ≤1 点 AUROC / ≤2 点 AUPRC；AURC 改善。
**G0（E0 后）**：所有切片 OverfitNN ≈ 最强模型（差 <1–2 点）→ 转"基准重建+诚实重评"论文，不上架构。
**【E0 判决：不触发】** 参照=冻结探针（E0 期最强可用模型）：head/mid 探针高于 best-OverfitNN
+3–6 点 AUROC（neg1c/neg1f/neg2 全轨 Δ>0.02）→ 非纯记忆，进入 E1。**尾部例外现象**：
tail 探针≈OverfitNN（neg1c Δ~0 / neg2 +1.3 点）→ H1 核心证据（尾部或为频率/记忆主导），
E1 须以完整最强基线复核尾部。完整基线栈属 E1，G0 最终确认待 E1。
**G1（E2 后）**：证据路由不优于频率法（3 种子不显著）或 oracle 上界 <2 点 → 弃路由，PU+泄漏评测单点论文。
**G2–G4**：见执行文档 §5 总表。W8 末中期路线决策。

## 9. 预训练污染通道（诚实边界）
