# M1 功能条件化残差：预注册与执行合同

日期：2026-11-24 ｜ 状态：已实现训练与统计入口，**尚无 M1 GPU 结果**

## 1. 范围与不可变事实

本合同执行 `论文证据/ProxyFunctionGap_科学故事与重启审计_2026-11-24.md` §5–7。旧 G1/G3/G4 对样本证据路由、nnPU 和旧路线的判决原样保留；M1 是新的、独立待证伪假设，不借重启推翻旧结果。

数据固定为 `e0-v1-id90-frozen`、pilot 40 实验、id90 冻结五折、neg1c/neg2 双轨。先 fold0；validation 选择，test 不参与 rank、收缩、checkpoint、阈值或晋级选择。不得重排划分、删除低一致 RBP 或把 smoke 当结论。

## 2. 四种同协议模型

冻结表征为 h，功能身份为 r：

- `independent`：每实验独立 MLP，复核对现有逐 RBP 强基线。
- `shared`：所有实验共享一个 MLP 输出，检验 M1a。
- `multitask`：共享表示 trunk + 无结构独立输出头，区分共享训练与低秩机制。
- `residual`：`g(h) + a_r^T U h`，检验 M1b；rank={4,8,16}，收缩={0.1,1,10}。

所有模型使用相同数据、batch=512、AdamW、学习率、label smoothing 与 validation 选择。身份打乱时，同一固定置换用于 train/val/test，其他设置不变。无收缩为 shrinkage=0。

## 3. 训练与 GPU 纪律

- 训练、基于模型前向的验证与预测必须显式 CUDA；程序启动即检查设备并执行数值探针。CUDA 不可用或 CPU 静默降级时 run=failed，证据写入日志，不得产出科学指标。
- 不使用旧 3–5 epoch 上限。每配置最多 1000 epoch 仅作故障保险；正常停止为 validation tail 宏平均 AUPRC 连续 20 epoch 未提高至少 `1e-4`。恢复历史最佳 checkpoint。
- 保存逐 epoch train loss、val BCE、tail AUROC/AUPRC、stale epoch、best epoch 与 checkpoint。收敛指预注册早停准则，不声称全局最优。
- 一种子一配置一 run；日志含 run_id、代码 SHA256、数据版本、配置、GPU、墙钟、输出与状态。

## 4. 顺序门与验收

| 阶段 | 必做对照 | 晋级条件 |
|---|---|---|
| M1a | shared vs independent，fold0/seed0 先排查，再三 seed | 双轨 validation tail AUPRC 平均下降≤0.02；若严重退化，先修多任务基线，不进入残差叙事 |
| M1b | residual 9 配置 vs independent/shared/multitask，三 seed | 仅按 validation 选 rank/收缩；双轨三 seed 均不退化且平均 tail AUPRC 至少+0.005，才进入机制对照 |
| M1c | train/test 一致身份置换 | 置换后收益接近原模型（差<0.002）则否定“功能身份”解释 |
| M1d | rank/参数匹配、无收缩、shared-only | 若收益只由大容量头部贡献且尾部受损，不晋级 |
| M1e | 仅 validation 标签拟合每功能适配器，test 只评一次 | 明确标 oracle；上界<0.02 或头部 AUROC/AUPRC 代价>0.01/0.02，停止完整架构 |
| M1f | fold0 三 seed→五折三 seed；晋级配置五 seed | ≥2 个预注册 T1 切片对完整最强基线显著；10,000 次窗口内配对 bootstrap p<0.05；双轨一致；头部 AUROC/AUPRC 代价≤0.01/0.02 |

任何 test 结果仅用于对应冻结配置的最终评价，不能回头修改选择规则。M1f 未全部通过时禁止写“方法胜利”“SOTA”或“预印本完整方法结果”。

## 5. 统计与产物

每配置保存 config、完整 history、metrics、val/test occurrence 对齐预测、每轨 checkpoint。统计程序先检查 schema、有限值、score/logit 一致性、窗口 occurrence 键和跨模型完全对齐；按 validation 选择配置。M1a/M1b 晋级统一由 `m1_gate.py` 执行，该程序没有 test 读取入口；最终 bootstrap 在实验内按窗口重采样，再宏平均实验，报告 AUROC/AUPRC 差、95%CI、双侧 p；OOD 必须另报 AUROC-OOD/FPR95/AURC。
