# G4 路线判决与 §9 主张-证据矩阵

日期：2026-11-24 ｜ 范围：E0–E6 首批实验链 ｜ 数据：`e0-v1-id90-frozen`、GRIMM EC_v2 split_1

## 1. G4 判决：触发，转基准/分析论文

原始胜利判据要求：至少 2 个 T1 切片对**完整最强基线**取得 3 种子以上显著增益，头部 AUROC 代价≤1点/AUPRC≤2点；拒识切片还要求 AURC 改善。

当前不满足：

- E1 五折×3种子的尾部显著增益是相对簇去重 kNN，不是对完整最强基线的机制胜利；离散路由、LoRA/full 和跨系主要为 fold0/seed0。
- G1 否定当前证据路由，未进入 E3；没有可提交的证据条件化机制。
- G3 否定当前 nnPU，未稳定降低天然候选 FNR。
- E5 没有跨双轨一致的拒识/AURC 改善；E6 的 MSP 虽提高 AUROC-OOD，FPR95/AURC 却不占优。
- E6 蛋白头尾方向与 RNA 不一致，不支持统一跨模态机制。

因此 **G4 触发**：停止架构扩张，论文转为 **泄漏受控的生物序列长尾/OOD 基准、强基线与误差分层**。不得把 pilot 结果写成主集最终结论或 SOTA 机制结果。

## 3. 新故事链：证据驱动的负结果路线

1. **标签与负例来自有偏实验过程**：E0 量化负例定义、同源冗余与有效样本量；这不是噪声脚注，而是模型比较的一部分。
2. **严格划分后仍存在真实频率分层**：E1 强基线显示 frozen、LoRA/full、检索各有头尾权衡；neg2 和跨细胞系暴露记忆近似。
3. **直观机制并未自动解决问题**：G1/G3 分别否定当前证据路由与 nnPU；负结果阻止无效架构扩张。
4. **OOD 结论依赖负例轨与评价工作点**：E5 双轨不一致；E6 MSP 的 AUROC 优势不等于 FPR95/AURC 优势。
5. **模态边界是实测结果**：E6 蛋白尾部检索显著占优、头部 BCE 显著占优，不能把 RNA 结论外推为统一规律。

贡献定位是：**数据审计协议 + 双轨强基线 + 频率/同源/跨条件切片 + 天然假阴性候选 + 拒识工作点分析 + 跨模态边界**。不是“证据路由/PU 新架构”。

## 4. 可写与禁止主张

可写：

- frozen BCE 在 RNA pilot 五折尾部显著优于簇去重 kNN，但这不是对完整最强基线的机制胜利。
- 解冻在 fold0/seed0 呈头部获益、尾部受损；RiNALMo 存在骨干×配方×负例轨交互。
- neg2 尾部和跨细胞系出现明显记忆近似；天然假阴性候选可被直接量化。
- 当前证据路由和 nnPU 未通过预注册止损门。
- 蛋白 split_1 呈显著频率×方法交互，拒识指标之间存在冲突。

禁止：

- “达到完整最强基线以上的 SOTA”“头部代价已满足≤1/≤2点”。
- “证据状态比频率更基本并带来因果增益”“连续路由优于离散”。
- “PU 降低假阴性”“统一证据分数实现可靠拒识”。
- “跨协议已完成”“主集五种子已确认”“蛋白低同源 identity 分桶已验证”。
- 任何无 run ID 的机制、物理锚或统计主张。

## 5. 论文完成前仍需补强的证据

以下是**基准论文的验证缺口**，不是恢复架构的理由：

- 主结论若要超出 pilot，需在冻结的主集协议上扩展相应基线与种子；不得用 fold0/seed0 替代主集结论。
- 跨协议、更多留出 RBP、低同源多种子统计仍未完成，应列为限制或后续基准扩展。
- 蛋白当前只有 split_1；若写五折结论必须实际跑完其余官方 splits。
- 论文图表只能引用有效 run；两次 E6 校准作废 run 和 E2 首轮尺度伪影不得进入主结果。
