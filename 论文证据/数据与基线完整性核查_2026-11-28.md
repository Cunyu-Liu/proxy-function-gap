## 2. 清洗方法？

峰处理沿用源基准：复制峰交集→互易 50% 同链并集→SMInput FC≥2→top20k cap→峰 5′ 碱基定交联→±50nt 101nt 链向窗→非 ACGU 跳过；GRCh38 + GENCODE v42 BASIC。neg1f 排除 no-op 已量化（1.82% 邻域残留）并作实现审计轨。PAR-CLIP 经 liftover v2 审计。蛋白 ESMC 嵌入 mean-pool 真实氨基酸位点；CAFA3 冻结 OBO/白名单 SHA 校验。**约 1% BASIC 宇宙外位点（fold=-1）不进入任何 CV train**（strict3train 显式三折）。

## 3. 数据分布？

RBP 位点 Gini 0.352、最大/最小 45.98×、逐实验 20k cap；head/mid/tail=100/28/18 实验；neg1c→neg2 组成差显著缩小（U 差 −0.041→−0.007）；蛋白标签中位支持度 2、频率桶 <10/10–29/30–99/≥100。频率、同源、条件三变量分开分层，不合成"证据强度"。Fig1 v2 可视化。

## 4. 数据是否泄露？

- id90 连通分量整折冻结；94.7403% 测试正例到训练正例最近邻 d_hom<0.7（描述划分设计，非零泄漏声明）。
- **旧加载器 fold=-1 缺口（21,420/2,168,739=0.9877%）已确认并修复**；旧 E1 主集撤回，旧泄漏率 0.0225% 含 validation 且重复计数，不作当前事实。
- strict3train 逐 run 校验 train ID/折计数、fold=-1 拒绝、occurrence 对齐。
- 预训练污染（RNA-FM/RiNALMo/ESMC 语料含人类）**不可排除**，已声明；跨系/跨协议/整 RBP 留出切片对污染相对免疫，主结论以这些切片为边界。
- GRIMM 为逐 EC 标签簇隔离，非全局 UniRef50 互斥；Test-2 是 pseudo-OOD（304/694 标签在训练出现）。

## 5. 数据质量？

双细胞系一致性（±50nt 重合中位 ~27%）、FC 敏感性、低一致 RBP 标记不静默删除；天然假阴性候选可测但非精确中心真值；neg2 有放回重复保留并按 occurrence 对齐；RNAcompete NaN 不填值不作负例、常数相关排除并保留支持数。

## 6. 数据集划分？

RNA 主集 id90 连通分量五折冻结（seed 20261122），strict3train：train=其余三显式折、val=(f+1)%5、test=f；neg1c/neg2 双轨。RNAcompete 序列 ID90 strict3train + 整物种×基因 RBP-OOD 双轨。蛋白五官方 split + 时间留出。80% 划分仅敏感性备用（id80 cd-hit 仍在跑，不作当前结论）。**冻结 test 不为任何新模式重排、不按 test 调参。**

## 9. 超参数怎么设计？

全部 **validation-only**：主集逐任务 val AUPRC 早停（patience20/min_delta1e-4/1000 epoch 故障保险）；kNN k∈{5,10,20} 尾部 val 宏 AUPRC 选择；RNAcompete fold0/seed0 val 宏 Spearman 冻结 weight_decay/k；微调 rank∈{4,8,16} fold0 val 尾部宏 AUPRC 单一全局选择；蛋白 val <100 标签宏 AUPRC 早停 + τ/阈值选择。**test 只由独立 evaluate 在配置冻结后读取；无 test 驱动选择。**

## 10. 有没有侧重 OOD 的测评？

四个独立 OOD 轴：① 整 RBP 留出（E5，12 RBP×双轨×三 seed，AUROC-OOD/FPR95/AURC 三指标联报，23/24 冲突）；② 跨协议 PAR-CLIP（9 RBP 外部描述性）；③ RNAcompete 整 RBP-OOD 回归轨（排序反转）；④ 蛋白 pseudo-OOD v2 + CAFA3 时间留出（执行中）。低同源 d_hom<0.60 切片作描述性分层。所有 OOD 结论按证据层级标注，描述性结果不画显著性。

## 结论

数据/清洗/分布/泄漏/质量/划分均有可验收证据与明确边界；benchmark 与 baseline 的**已验收部分**支撑当前预印本主张，**执行中部分**（RiNALMo 双矩阵、CAFA3、LoRA/full）过门后补齐跨骨干与容量对照。无未声明的缺口。
