## 2. 时间留出、NK/LK 与训练注释

- **t0→t1 是主时间轨。** t0 是训练、早停、阈值和模型选择的唯一来源；NK/LK t1 只在模型与阈值冻结后评价。不存在第二个历史快照，因此 t0 三折只是组隔离代理验证，不冒称第二次时间 OOD。
- NK=官方 type1，表示该蛋白在该本体原先无实验知识；LK=官方 type2，表示已有部分实验知识。角色逐本体读取，不把全局蛋白身份当作角色定义。
- 忠实 CAFA 轨保留 LK 的 t0 部分知识，不因它出现在 t1 清单就删除其合法 t0 注释。压力轨才按固定同源阈值剔除训练/验证序列，t1 成员与真值不变。
- t0 共 66,841 蛋白、386,197 原始蛋白–GO 行；过滤后仍为 **386,197 唯一行、66,841 蛋白，拒绝/重复为 0**。过滤合同是：三列格式、训练序列存在、GO 在同版本 OBO 中有效且非废弃、namespace 一致；alt ID 可规范化，规范化后重复必须审计。
- t0 文件由组织者预过滤为实验注释，没有逐行 evidence code；不得声称本脚本重新核验了 EXP/IDA/IMP 等代码。未标注 GO 不等于实验否定。
- `t0_proteins.tsv.gz` 保留 UniProt accession、描述、MD5、长度和非标准氨基酸计数；`target_proteins.tsv.gz` 保留 CAFA ID、官方 external ID、taxonomy、描述和序列审计。official external ID 不被冒称 UniProt accession。

## 3. 严格三折与实名白名单

- t0 按完全序列 MD5 分组，同一序列组只进入一个 fold，完全重复序列不会跨折。当前没有完成 t0 全对全同源聚类，因此不得把这三折称为同源簇独占；可行的 t1→t0 BLASTP 同源审计与压力隔离见第 6 节。
- fold 由 `SHA256(homology_group_id) mod 3` 确定，不读取 t1，也不按 t1 表现调折。每折 `fold{k}_train_whitelist.txt.gz` 为其余两折实名 ID，`fold{k}_validation_whitelist.txt.gz` 为当前折实名 ID。
- 数据加载器必须读取白名单；不得用“全集减 validation/test”的补集表达式构造 train。t1 没有 fold，也不进入任何 t0 白名单。

## 4. leaf 真值与本体传播

- `t1_groundtruth_leaf.tsv.gz` 保留全部 **7,173 原始行**及状态；完全相同的 `(protein, source GO)` 有 **119 行重复**，评价使用 **7,054 唯一对**。重复行可审计，不静默丢弃原始记录。
- 历史 OBO 不能覆盖全部较晚 t1 术语：**120 个唯一 leaf 对不在该 OBO 中**。这些官方标签仍进入评价，传播仅为 self-only；不得按训练过滤规则删除，也不得借当前 GO 补祖先。

## 5. BPO 上游异常：保留、分型、不得静默修复

1. `T2089630000462` 在 BPO NK 清单中，但不在官方 `leafonly_BPO.txt`。忠实轨保留其 NK 成员记录，官方 NK 清单数仍为 849；有 leaf 真值、可计算蛋白级指标的 NK 为 848，覆盖率必须报告为 848/849。不得补标签，也不得把它作为全零真值蛋白。
2. `T2089630003090` 有 BPO leaf 真值，但不在 NK/LK 清单。其真值与 `UNLISTED` 状态保留在审计中，不分派到 NK 或 LK，也不进入角色分母。
3. 两类异常都写入 `upstream_anomalies.tsv.gz` 和汇总。若未来建立修复轨，必须另命名并同时报告忠实轨，不能替换官方清单。

## 6. 完全重复与同源隔离审计

- t0：66,841 ID、65,945 唯一序列；targets：130,827 ID、126,138 唯一序列；空序列均为 0。含非标准氨基酸的 t0/target 记录分别为 210/457，未静默过滤。
- `exact_sequence_groups.tsv.gz` 对全部 t0/target 建立 MD5 组；评价仍按官方 ID 和清单，不去重改变分母。t0 与 3,328 benchmark 蛋白之间有 **1,902 个完全序列重叠组**，主轨保留并显式报告。
- `t1_to_t0_homology.tsv.gz` 报告每个 benchmark ID 的 t0 最佳命中、identity、`min(alnlen/qlen, alnlen/tlen)` 覆盖度、完全重复标记和分桶；汇总按本体×NK/LK 拆分。
- 压力轨在 bilateral coverage≥0.5 下分别剔除 identity≥30%/50%/90% 的 t0 train 与 validation ID，输出 `stress_id*_fold*_whitelist.txt.gz`；t1 不变。阈值不得按 test 成绩移动。
- BLASTP 使用 `evalue=10`、`max_target_seqs=1000`，逐对输出 identity、alignment length、query/target length、E-value 和 bitscore，共 888,699 条命中。这是固定参数、可复跑的近似审计，不是“绝对无同源”的数学证明；`no_detected_hit` 不等于生物学上无同源。

| 90–<100% | 222 |

- 30%/50%/90% 压力轨分别剔除 17,537/8,500/4,551 个 t0 ID；角色分桶、工具二进制 SHA 见 `cleaning_summary.json` 和 `frozen_manifest.json`。100% identity 桶与 1,902 个 MD5 重叠组分别报告，不混为同一指标。

## 7. 标签频率桶与评价合同（仅定义，无数值成绩）

- 频率以 t0 清洗后的 direct 蛋白数为基准：`0`、`1–4`、`5–19`、`20–99`、`100–499`、`≥500`；t0 propagated 频率另列，二者不混用。唯一官方 leaf 对的实测分布如下（BPO 含 UNLISTED 审计真值，角色评价时另过滤）：

| 本体 | 0 | 1–4 | 5–19 | 20–99 | 100–499 | ≥500 |
|---|---:|---:|---:|---:|---:|---:|
| MFO | 284 | 166 | 252 | 305 | 451 | 233 |
| BPO | 203 | 424 | 756 | 1,018 | 984 | 193 |
| CCO | 43 | 29 | 86 | 248 | 376 | 1,003 |

- 主指标：CAFA protein-centric Fmax 与 Smin，阈值网格 0.01–1.00；阈值只在 t0 validation 选择，同时报告 coverage。不得用 t1 选阈值。
- 长尾补充：macro AUPRC 在报告 slice 内对至少一个正例的 GO 标签等权平均；必须报告有效标签数，undefined 不得填 0。普通 AUROC 不替代 CAFA 指标。
- OOD 报告维度：本体×NK/LK×频率桶×完全重复×同源桶，并附可评价蛋白数、coverage 和分母。BPO NK 的 848/849 与 UNLISTED 必须单列。
- 所有 3,328 个 benchmark ID 均有 target 序列；模型分数、BLAST/naïve 基线和文献复现均属于后续实验，不在本数据卡中。

- 独立 `--verify-only` 重读所有 SHA、6 个主三折白名单、序列组/MD5 跨折关系与 BPO 异常，结果 `passed`。验收见同目录 `verification.json`；另一轮独立行数复核见 `independent_audit.json`。

## 9. 证据边界

- t0 内没有可靠更早历史快照，所以严格三折是完全序列组代理验证，不是新增时间切分；没有 t0 全对全聚类证据时，不主张 validation 与 train 无远程同源。
- 两个官方压缩包未附单独数据 LICENSE；内部研究落地不构成再分发授权。评估仓库 GPL-3.0 不自动等同于全部上游数据许可证。
- **GRIMM EC_v2 五划分与 pseudo-OOD 是另一任务、另一标签体系和另一划分，不能替代 CAFA3 时间留出。** 本卡冻结数据与协议，不等于取得 CAFA 模型性能或 SOTA。
