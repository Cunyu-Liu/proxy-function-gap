## 0. 必须先改的判决

1. **最高优先级：E5/E6 拒识指标存在三类实现错误，旧结论全部阻断。** E5 energy 用 `abs(logit)` 当 OOD 分数，方向反了；E5/E6 AURC 从最高不确定性端累计，方向反了；旧 E5/E6 `fpr95` 实际是 `ood_tpr_at_known_fpr5`。E5 旧 run 与当前新协议单 pair 均不能直接引用其 OOD 表，E6 旧 FPR95/AURC 和“MSP/energy 后两项不占优”全部撤回。E6 修正量已从本地逐样本分数独立回算，见 §8。

| 轨道 | 状态 | 准确语义与禁止表述 |

- **修正前不得写“id90 跨折泄漏为零”“BASIC 外样本不进 CV”“闭集划分严格无泄漏”。**可以写“设计了连通分量整折，但独立审计发现未分配窗口的训练使用缺口”。

### 6.3 预训练不可排除项

|---|---:|---:|---:|---|

### 8.4 指标覆盖缺口

- **未证实：**worst-group、precision@coverage、unknown recall 尚未形成完整有效报告；ECE/Brier 受大量负标签主导，不能证明尾部校准。
- OOD 工作点、温度、阈值只能由 validation 选择；test 上挑 MSP/energy/kNN 中最有利者不构成预先指定胜者。
- 标准 FPR95 与 `ood_tpr_at_known_fpr5` 可双报，但必须分别命名、说明方向与分母。

## 10. 可执行优先级

### P0：先阻止错误结论进入论文

1. **E1 foldfix 必须完成以下全部验收门槛，缺一项都不得恢复主集最终验收：**
   - **语义与版本门：**先预注册选择“排除所有未分配 fold=-1 样本”或“把其确定性分配到唯一 fold”，不得逐折临时选择。若排除，train 正负例都必须显式 `.isin({0,1,2,3,4}-{test,val})`，禁止补集过滤；若重分配，必须新建 E0 划分版本并证明每样本只属于一个 fold。新 `data_version`、代码 SHA256、输出目录和 run ID 均不得复用旧 `e0-v1-id90-frozen-main` 产物，历史冻结物不覆盖。
   - **合成反例与本地预检门：**用含 fold=-1、NaN、test/val 和三个 train fold 的最小数据验证：NaN 必须报错，fold=-1 按预注册语义排除或唯一分配，train 恰好三个预期 fold；test/val 永不入 train。对 `ILF3_HepG2/fold0`，若采用排除语义，应复现每轨比旧公式少303个正例，而不是只改代码名。
   - **逐任务 ID 审计门：**每个 fold×experiment×track 输出 train/val/test 的来源 fold 计数、行数、正/负数、有序 ID SHA256；独立加载器从原始窗口重建并逐键一致。train 不得含 -1/NaN/非预期 fold，train/val/test ID 两两不交；neg2 有放回 occurrence 仍完整，不得借修复静默去重。
   - **严格泄漏门：**只用当折三个 train fold 重新计算 window/cluster 重叠，train–val/test 的 ID 与 id90 连通分量交叉均符合预注册零重叠要求；不得沿用把 validation 也算 train 的旧0.0225%口径。test 键、标签和原始冻结 fold 保持不变。
   - **全量新版本重跑门：**在同一 foldfix 版本重跑15个 modern（5 fold×3 seed）与5个 kNN；逐 run 必须有 `require_cuda`、CUDA 数值探针、device/name、代码/输入哈希及 completed 记录，禁止 CPU 回退。epoch/k 仍仅由 validation 选择，test 不参与选择。随后重新生成合并预测、CV、配对 bootstrap、低同源及其他受影响下游，禁止把旧 NPZ/TSV 拼入新版本。
   - **独立三遍验收门：**①文件/schema/行数/有限值与146实验双轨覆盖；②配置、fold、seed、CUDA、ID/occurrence 和早停/选点对齐；③从逐折结果和逐窗预测独立回算 CV、bootstrap、CI/p 与分层。全部通过后另出带 foldfix 版本号的新报告；旧报告只留撤回记录，不以文字声明替代新 run。
2. **保留 FPR95/AURC 撤回记录，按模块分开收尾。**E6 v2 已完成标准定义、合成反例、原始分数回算和独立验收，当前方向见 §8.3；E5 仍需在 foldfix 后重跑并以正确公式重算。旧列只以 `ood_tpr_at_known_fpr5` 留痕，不恢复旧工作点优劣。
3. **GRIMM 论文主表使用已验收的五 split convergence + OOD v2 链。**汇总 `E6-five-split-summary-20261125-080318-ZDLg6Y` 与独立验证 `E6-five-split-independent-verification-20261125-080348-ZDLg6Y` 均 accepted；旧 split_1 五 epoch 和旧 OOD 验证只进历史附录，不与新协议混均。
4. **修正证据归属。**0.0713 改挂主集 fold0 run；pilot 写 0.0641。所有图表扫描同类 pilot/main/seed 混写。
5. **E1 主集旧汇总全部冻结为撤回的历史审计。**旧20个配置的 run manifest、预测 occurrence 对齐、有限值与报告回算只证明旧产物内部一致，不能抵消 train fold 和 CUDA 缺陷；只有上述 foldfix 全部门槛通过后，新 run 才可升级为最终主集 test。

### P1：补齐会改变基准可信度的实验

1. **PAR-CLIP：**patience20 三 seed 与唯一基因匹配、±300nt排除的同协议 neg2 已完成三检，冻结为9 RBP外部描述性。继续保留三切片 AUROC/AUPRC 与匹配覆盖限制，不补写 FPR95/AURC。若要加强证据，需独立生物重复或预定义非位点采样框；若写17 RBP，须补其余8个 eCLIP 训练实验与兼容划分。
2. **RNA OOD：**低同源和跨细胞补 3 seeds；整 RBP 留出扩集合、3 seeds、validation 早停，双轨同时报 AUROC、标准 FPR95、AURC。family 不作为主 far-OOD，除非另有可靠家族注释。
3. **强基线：**优先将 LoRA/full、RiNALMo、离散路由做同协议多种子；补 Pysster/PrismNet/BERT-RBP 至少关键复现或明确缩小“完整强基线”表述。不得按 test 结果挑基线。
4. **GRIMM：**补五 split 数据卡/逐标签重叠审计、BLAST/DIAMOND 检索和实测 MMseqs2 identity 桶；需要“完整强基线”时再补 LoRA/代表功能模型。Test-2 始终称 pseudo-OOD。
5. **预训练与注释：**把“免疫”改为“不可排除+互补切片”；可核查语料时报告序列重叠，不可得时保留限制。不得虚构证据代码过滤。

### P2：范围扩展，不能先于 P0/P1

1. RNAcompete/CAFA 若要成为论文 benchmark，先分别建立版本化数据卡、任务定义、泄漏/时间划分与同协议基线；否则只列未来工作。
2. 补 worst-group、precision@coverage、unknown recall 与温度前后校准；预先固定工作点。
3. 其他候选数据集只在科学问题需要时扩展，不以数量替代当前数据修复。

## 11. 最终可写与不可写

**可写（已证实）：**

- 已建立双负例轨、id90 连通分量划分及多维数据审计；但独立复核发现 fold=-1 训练使用缺口，本地 foldfix 仅处于未部署、未重跑准备阶段，远端执行副本仍旧，旧主集结果已撤回最终验收。
- pilot 五折三种子 frozen BCE 显著优于簇去重 kNN，但这不是对完整最强基线的胜利；共享加载器的其他训练结果按 §6.4 单独定级，不能借 pilot 结果覆盖主集缺口。
- PAR-CLIP 当前是 9 RBP、patience20 三 seed 外部描述性切片；三轨 AUROC 为0.646192/0.607869/0.655701，迁移高度 RBP 依赖，三 seed 非独立生物重复且负例限制仍在。
- GRIMM 五 split 新协议下 BCE 在所有频率桶优于 deep-kNN；OOD v2 中 MSP/energy 的 AUROC-OOD、FPR95、AURC 在5/5 split 描述性方向均优于 deep-kNN，Test-2 仍是 pseudo-OOD，不附新增 FPR95/AURC 区间。

**不可写（未证实）：**

- BASIC 外样本不进 CV、id90 跨折零泄漏、预训练污染被跨条件切片免疫。
- 旧 FPR95 数字及其 energy/deep-kNN 工作点优劣结论。
- 蛋白尾部 kNN 普遍更强、RNA/蛋白统一头尾规律。
- PAR-CLIP 17 RBP 已完成模型验证；RNAcompete/CAFA 已实测。
- 完整强基线、主集最终性能、低同源/跨系/留出多种子、最终五种子或 SOTA 已确认。

本文件是独立审计，不替代各阶段正式验收报告；新增实验只有在 run ID、配置、划分、种子和三遍核验齐备后才能改变上述三态。
