## 0. 路线判决与证据语法

### 0.1 当前唯一主线

论文问题不是“某个新架构能否统一长尾、PU 与 OOD”，而是：

> **当同源泄漏、负例构造、实验条件、评测工作点和训练协议被显式控制后，生物序列模型的头尾优势、跨条件迁移与拒识结论还剩下多少？哪些直观修复在严格对照下并不成立？**

贡献是一套可复核的基准与误差分层证据，不是 SOTA 机制。G1/G3/G4 的历史判决保留；M1a 是方法线的**止损终点**，不是又一次“重启”。

### 0.2 证据层级

| 标记 | 含义 | 可支持的写法 |
|---|---|---|
| **P-test** | 通过 foldfix 数据合同验收后的 RNA pilot 40 实验；多折/三种子 test；预注册配对统计 | 仅 foldfix 重跑并重新验收后可作 pilot 范围内的对照结论，不外推主集 |
| **P-test-legacy** | 旧加载器产生的 pilot/下游闭集结果 | 仅保留历史数值与统计痕迹；受 fold=-1 训练缺口影响，不支持当前科学主张 |
| **D-test** | 单折、单 seed、单划分或外部协议描述性 test | 现象与假设生成，不作稳定性或机制结论；旧闭集 D-test 同样标为 legacy |
| **M-desc** | 主集或外部数据上的描述性评测 | 明确样本与混杂，不能冒充多种子确认 |
| **V-gate** | validation-only 门控 | 只判断是否晋级，不报告 test 性能 |
| **H-protocol** | 旧训练协议的历史结果 | 只作协议对照，不与新协议混池 |
| **5S-test** | 蛋白统一新协议五划分、三 seed test | 新协议五划分范围内的结论 |

文中“显著”只在通过当前数据合同验收的 P-test/5S-test 中使用。旧 P-test-legacy 即使已有配对 bootstrap，也只能说历史表中的配对差达到统计阈值，不能升级为无泄漏泛化结论。单 seed、validation、在跑作业和计划均不进入确认性结论。

## 1. 自我反省：旧故事把“做过什么”误当成“为什么必须这样做”

旧链条“数据审计→强基线→证据路由→PU→OOD→蛋白”只是项目日程。它隐含了四次未被证据授权的跳跃：

1. 从“负例有偏”跳到“某种证据变量就是正确干预”；
2. 从“头尾方法不同”跳到“样本级路由应当有效”；
3. 从“存在假阴性候选”跳到“PU 风险应当改善召回”；
4. 从“跨条件映射不稳”跳到“同一不确定性分数应当可靠拒识”。

M1 又重复了同类错误：因为共享残差在概念上能连接这些现象，就把它写成故事的必然终点。M1a 未过门说明，概念连贯不是方法有效的证据；其旧闭集加载链缺口又限制了数值解释。新链条因此以**先审计测量合同，再排除替代解释**为推进原则：负例偏差要求把 id90 隔离从设计目标落实为可验收训练合同；foldfix 后的频率分层才允许进入强基线比较。旧路由/PU 只留历史止损记录，当前跨协议、OOD 和蛋白结果只承担外部有效性及边界检验，不再为旧方法补写机制。

## 2. 环环相扣的科学证据链

### S1｜实验过程与负例定义先决定“模型在学什么”

**现象。** 主集 fold0 的同一冻结 RNA-FM 探针，AUROC 从 neg1c 的 0.8901 降到 neg2 的 0.8188，差值 −0.0713。neg1c 的正负例 U 含量差为 −0.041，而 neg2 的转录本匹配显著缩小组成差异。neg1f 的 ±300 nt 排除 no-op 只影响少量邻域样本，不能解释整条 neg1c→neg2 降幅。

**对照。** 相同正例、冻结表征与探针，仅改变负例定义；neg1f 与修正后的 neg1c 作为实现伪影对照。

**run 与证据。** `E0-frozen-probe-20261122-095015-ZDLg6Y`（D-test，主集 fold0）；`E0-leakage-quant-20261122-102238-ZDLg6Y`（数据审计）。原始 `probe_mainfold0_summary.tsv` 回算：0.8188−0.8901=−0.0713。

**能排除。** 不能把 neg1c 的高分全部解释为 RBP 功能识别；也不能把全部轨间差异归因于 neg1f no-op。

**不能排除。** 负例的转录本/表达匹配仍不完全；残余序列组成、协议批次和基础模型预训练污染均可能影响分数。这里没有识别出唯一的生物因果变量。

**下一实验为何必要。** 若划分仍允许近重复跨折，即使换成 neg2，也可能用记忆替代功能泛化。因此下一步不是直接发明“证据状态”，而是先冻结同源隔离划分，再检验频率分层是否仍存在。

### S2｜id90 是划分设计目标，但旧闭集加载器破坏了三折训练合同

**E0 已证实事实。** 主集采用 id90 连通分量整折设计；2,147,319 个有 fold 归属窗口中，94.7403% 测试正例到训练正例的最近邻 `d_hom<0.7`。旧泄漏表报告宏平均 0.0225%，但其“train”实际包含 validation，且每正例被两条轨重复计数，不能解释为严格三折训练泄漏率。以上仅描述划分设计与序列相似性，不证明旧训练实现无泄漏。

**已发现缺口。** 主集 2,168,739 个正例中有 21,420 个 `fold=-1`（0.9877%）；旧 E1 的布尔条件把这些 BASIC 外正例保留在每个 train 折。`ILF3_HepG2/fold0` 的实际训练数比只取 folds 2/3/4 多 303 个正例/轨，代码条件、数据表与旧 run 产物三者一致。因此“BASIC 外样本不进 CV”“id90 跨折泄漏为零”和“闭集严格无泄漏”全部不可写。

**旧 pilot 仅作历史记录。** 旧五折三种子的尾部 BCE−kNN ΔAUROC 为 neg1c +0.02515、neg2 +0.02789，历史 bootstrap 双侧 p=0.00019998；对应 ΔAUPRC 为 +0.03727、+0.04219。统计：`E1-paired-bootstrap-20261123-085242-ZDLg6Y`（**P-test-legacy**）。这些算术和配对统计可以回算，但同一加载器风险使“严格划分后 BCE 优于检索”的科学解释撤回，不能支撑最终主张，也不能外推主集。

**当前状态与下一步。** 旧 E1 主集报告已撤回验收，主集 foldfix 新版本正在重跑；旧主集还缺统一显式 CUDA 证据。foldfix 必须固定新版本、排除或唯一分配未分折样本、逐 run 审计 train/val/test 正例 fold 计数与 ID hash，并以显式 CUDA 和严格三折 cluster leak 检查验收。它是**修复数据合同并重跑**，不是根据 test 调参；只有重跑后的 pilot/主集及必要下游通过验收，才能恢复相应性能主张。

### S3｜旧微调与骨干对照只保留历史现象，foldfix 前不作权衡结论

**历史现象。** 旧 fold0/seed0 上，full 相对 frozen 在 neg2 头部 ΔAUROC=+0.01160、尾部 −0.03109；LoRA 同样头部获益、尾部受损。RiNALMo 的 BCE 尾部差在 neg1c 为 +0.01456，在 neg2 为 −0.00728。离散频率路由在 neg1c 尾部比最佳 kNN 高 +0.04646，但 neg2 尾部仅高 +0.00594。

**对照。** 同折同 seed 的 frozen/LoRA/full；RNA-FM/RiNALMo 的 BCE/kNN；只用 validation 按频率层选择候选的离散路由。这些对照来自旧闭集加载链，不能拼成“完整五折胜利”，也不能作为当前头尾权衡的最终证据。

**run 与证据。** 微调与三档对照：`E1-mode-comparison-20261123-124510-ZDLg6Y`（D-test-legacy）；骨干对照：`E1-mode-comparison-20261123-145602-ZDLg6Y`、`E1-mode-comparison-20261123-145603-ZDLg6Y`（D-test-legacy）；离散路由：`E1-discrete-router-20261123-150430-ZDLg6Y`（D-test-legacy）。

**能与不能排除。** 这些数值只说明旧协议下曾观察到非单调排序；fold=-1 训练缺口、单折单 seed、优化配方和收敛差异均未排除。因此“解冻更多参数必然改善尾部”等强假设并未获得合格的最终检验，离散路由现象也不证明样本级 `d_hom` 是正确路由变量。

**下一实验为何必要。** 先修复并验收数据合同，再决定是否重跑必要的模型容量、检索和骨干对照。频率层组合仍可作为预注册的候选强基线，但任何复杂路由或标签修复都必须在 foldfix 后重新比较，不能沿用旧闭集优势。

### S4｜旧路由与 PU 负结果保留止损记录，但不冒充修复后闭集证据

#### S4a｜旧 `d_hom` 路由结果受同一加载器风险影响

**历史现象与对照。** 相对频率路由，evidence 的 neg1c 尾部 ΔAUROC=−0.00432（历史 p=0.0030），joint 为 −0.00365（历史 p=0.0106）；neg2 未显示稳定改善。对照使用同一 frozen 骨干、双轨、三种子、validation Platt 校准和逐窗配对 bootstrap。

**run 与证据。** `E2-paired-bootstrap-evidence-20261123-160559-ZDLg6Y`、`E2-paired-bootstrap-joint-20261123-160559-ZDLg6Y`（**P-test-legacy**）。首轮未校准尺度伪影已作废；fold=-1 训练缺口又使剩余结果不能承担“严格同协议下机制无效”的最终结论。

**证据边界。** 当前可执行判决仍是不恢复路由扩张；科学上只记录旧实现未显示增益，不据此否定所有连续状态、其他证据变量或所有路由结构。未运行的 E3 不得补写 oracle 或消融结论。

#### S4b｜天然假阴性是 E0/E4 审计事实，旧 nnPU 效果仍需合格协议

**审计事实与历史对照。** 源系负例与目标系同 RBP 位点重叠可定义天然假阴性候选；窗口包含重叠只是操作定义，不是精确交联中心真值。旧 nnPU−naive 的候选 ΔFNR 在 π=0.05、neg2 为 +0.02163（历史 p=0.0024），π=0.1/0.2 双轨均恶化；候选真值没有参与训练。

**run 与证据。** 候选审计 `E4-natural-truth-audit-20261123-164823-ZDLg6Y`；旧三种子统计 `E4-g3-bootstrap-20261123-172506-ZDLg6Y`（**P-test-legacy**）。前者支持“未检出≠阴性”的评测事实，后者受闭集训练合同缺口影响，不能作为最终方法效果证据。

**证据边界与下一步。** 当前 nnPU 先验与风险估计没有形成可验收的稳定改善，路线不因此重启；当前失败也不否定一切 PU 估计量。主故事不再用旧路由/PU 数值推进最终主张，先完成 foldfix 主集和必要下游影响评估，再决定是否保留这些历史对照。

### S5｜当前外部推进依赖已纠正的 PAR-CLIP 描述性结果，负例来源仍是核心分层变量

**当前现象。** 最新 patience20 跨协议三 seed 外部描述性结果中，9 RBP 宏 AUROC 为 eCLIP-neg1c **0.646192±0.002641**、eCLIP-neg2 **0.607869±0.002595**、PAR-CLIP 同协议 neg2 **0.655701±0.004951**；逐 RBP 仍高度异质。旧 fold0/seed0 跨细胞系结果与闭集 E1 共用加载链，现只保留历史痕迹，不再支撑当前跨条件主张。

**对照。** 跨协议固定 eCLIP 头，以 eCLIP validation 按 patience=20、min_delta=1e-4 选 epoch；PAR-CLIP 不参与训练或选参。三种外部负例切片分别报告：eCLIP neg1c、eCLIP neg2，以及其他 RBP 的 PAR-CLIP 位点经唯一基因匹配与目标位点 ±300 nt 排除构成的同协议 neg2。三者不混合计算，也不把切片间差值解释为模型提升。旧跨系 run `E1-cross-cell-modern-20261123-151445-ZDLg6Y`、`E1-cross-cell-knn-20261123-152246-ZDLg6Y`、`E1-mode-comparison-20261123-152722-ZDLg6Y` 均降为 D-test-legacy。

**run 与证据。** 当前跨协议 seed0/1/2 分别为 `E5-parclip-cross-protocol-contract-p20-20261125-065228-ZDLg6Y`、`E5-parclip-cross-protocol-contract-p20-20261125-065619-ZDLg6Y`、`E5-parclip-cross-protocol-contract-p20-20261125-065953-ZDLg6Y`（M-desc，9 RBP、三 seed、外部描述性）。

**能排除。** 当前结果不支持“一个 eCLIP 训练头可在不同 RBP、条件和协议间保持稳定判别力”的强假设；跨协议结果必须按 RBP 与负例定义分层呈现。

**不能排除。** eCLIP 两轨仍有协议、细胞环境和转录本组成混杂；PAR-CLIP 同协议 neg2 的其他 RBP 位点可能是目标 RBP 未观测位点，唯一基因筛选也改变覆盖和重复结构。三 seed 不是独立生物重复，不能作显著性或机制推断；两种负例来源的宏 AUROC 差不是协议校正的因果效应。

**历史状态撤回。** 本文此前引用的 30-epoch seed0 数字和 patience10 三 seed 工程状态均已被上述合同结果替代；patience10 不得称为满足20 epoch 停滞。历史 run 保留在 E5 报告中，不再支持当前数字。

**下一实验为何必要。** 分类分数在条件改变时不稳，并不自动意味着模型能识别“何时不知道”。必须在独立 OOD 任务上检查排序、工作点及指标语义，同时把描述性方向与逐 seed 不确定性分开。

### S6｜当前 OOD 推进只采用蛋白 OOD v2；三指标同向仍不等于可靠拒识

**当前现象。** 蛋白 OOD v2 修正后，MSP 与 energy 在 **5/5 split** 的 AUROC-OOD、标准 FPR95 和修正 AURC 三项描述性方向均优于 deep-kNN。该方向保留，但不升级为统一拒识或跨模态机制结论。

**对照。** 蛋白使用 seed-ensemble 的 MSP/energy 与确定性 deep-kNN，在五 split Test-1/Test-2 pseudo-OOD 上按 `e6-ood-v2:fpr95=id_at_ood_tpr95;aurc=ascending_ood_score` 重算。三指标成组报告，当前方向一致不能改写为指标冲突。

**run 与证据。** OOD 离线重算 `E6-ood-metric-recompute-v2-20261125-072246-ZDLg6Y`，五划分汇总 `E6-five-split-summary-20261125-080318-ZDLg6Y`，独立语义回算 `E6-five-split-independent-verification-20261125-080348-ZDLg6Y`（5S-test 的跨 split 描述性汇总，`retraining=false`）。

**能排除。** 旧蛋白 FPR95/AURC 实现不能支持任何当前工作点结论；单项 AUROC-OOD 也不足以宣称统一可靠拒识。

**不能排除。** 蛋白 Test-2 只是 pseudo-OOD；当前方向来自 seed-ensemble 分数，只有 AUROC-OOD 既有配对区间，没有新增 FPR95/AURC 逐 seed 区间或跨 split 显著性检验，不能证明逐 seed 稳定、跨蛋白泛化或真实未知 EC 发现。

**RNA 历史撤回。** 旧 E5 energy 的分数方向、AURC 累计方向与 FPR95 命名均存在错误，且旧闭集训练链还有 fold=-1 风险；本文此前引用的 `E5-rbp-holdout-20261123-174134-ZDLg6Y` RNA OOD 数值及“双轨不一致”表述全部撤回。合格多种子扩展留出仍未完成，不得用旧表补位。

**蛋白历史撤回。** 旧 FPR95 实为 OOD TPR@ID-FPR5，旧 AURC 的累计方向也错误；旧数值、风险覆盖表及本文此前“蛋白 MSP/energy 后两项更差”的表述全部撤回。旧独立验证 `E6-five-split-independent-verification-20261125-045348-ZDLg6Y` 仅保留纠错前痕迹，当前语义以 `E6-five-split-independent-verification-20261125-080348-ZDLg6Y` 为准。

**下一实验为何必要。** 最后需要检验蛋白分类优势是否覆盖所有频率桶，并把“当前模态上的基线排序”与“可跨模态外推的统一机制”严格区分。

### S7｜蛋白新协议 25/25 频率桶均为 BCE 优势，模态外推仍需独立证据

**现象。** 统一新协议五个 split、五个频率桶（含全部桶）共 **25/25 单元格**均为 BCE−deep-kNN Δmacro AUPRC>0，且每个单元格 95% CI 排除 0、双侧 p=0.00019998。`<10` 桶为 +0.264211 至 +0.277586，`10–29` 桶为 +0.330767 至 +0.362792；≥100 桶也为 +0.195413 至 +0.212319。当前蛋白故事是全频率桶一致的基线优势。

**对照。** 新协议固定 ESMC-300M 960 维冻结嵌入、BCE 线性头、三 seed、validation `<100` 标签宏 AUPRC 早停与 τ/阈值选择、10,000 次按 EC 标签配对 bootstrap。五划分最佳 epoch 均由 validation 曲线产生，未把 1000 epoch 故障保险当收敛证明。跨 split 只作等权描述性汇总，不 pooled 标签或构造跨 split 显著性。

**run 与证据。** 新协议 split_1–5：依次 `E6-grimm-frozen-baselines-20261124-085329-ZDLg6Y`、`E6-grimm-frozen-baselines-20261124-070400-ZDLg6Y`、`E6-grimm-frozen-baselines-20261124-104344-ZDLg6Y`、`E6-grimm-frozen-baselines-20261124-123513-ZDLg6Y`、`E6-grimm-frozen-baselines-20261124-171811-ZDLg6Y`；汇总 `E6-five-split-summary-20261125-080318-ZDLg6Y`、独立验证 `E6-five-split-independent-verification-20261125-080348-ZDLg6Y`（5S-test）。

**能排除。** 在当前 GRIMM EC_v2、冻结 ESMC-300M 和收敛协议下，检索在低频标签上必然占优的强假设被五划分全桶结果否定。

**不能排除。** 这不证明 BCE 在其他蛋白任务、骨干或训练协议中普遍更强，也不证明 RNA 与蛋白共享机制。蛋白截断、逐标签而非全局簇隔离、预训练污染和注释过程仍是限制；RNA 二分类与蛋白多标签任务不等价，25/25 方向一致也不是跨模态统一证据。

**历史撤回。** 旧 split_1 五 epoch 的“头部 BCE 强、尾部 kNN 强”仅保留为未收敛训练协议的历史对照（`E6-grimm-frozen-baselines-20261124-001704-ZDLg6Y`，H-protocol）；它与新协议不混池，不再用于主张头尾反转或纯 split 因果效应。

**下一实验为何必要。** 五划分完整性和 OOD v2 语义已验收，无需恢复路由或残差。后续若扩展，应检验其他蛋白任务/骨干与真实未知功能设定，以确定当前基线结论的外部边界。

### 4.1 推荐题目

- **背景：** 生物序列基准同时受同源冗余、构造负例和条件特异标签影响；若只报告随机划分总体指标，模型比较可能混合记忆、技术偏差与真实泛化。

- **蛋白分类与 OOD：** 统一新协议五划分的 25/25 频率桶均为 BCE>kNN；OOD v2 的 MSP/energy 三指标方向虽均优于 deep-kNN，但仅限 seed-ensemble pseudo-OOD 描述，不能替代逐 seed 区间或真实未知功能验证。
- **结论：** 当前证据支持数据审计、已纠正外部/OOD 切片与蛋白协议边界，不支持统一证据路由、PU 或残差机制，也不支持旧主集最终性能。
- **终稿待补：** 只有 foldfix 后 E1 主集汇总、严格三折训练审计、显式 CUDA 和统计验收全部通过，才能决定是否加入 146 实验数字；重跑不是调参，不能用旧数字或预期方向替代新实测。
