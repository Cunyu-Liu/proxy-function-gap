## 0. 路线判决与证据语法

### 0.1 当前唯一主线

论文问题不是“某个新架构能否统一长尾、PU 与 OOD”，而是：

> **当同源泄漏、负例构造、实验条件、评测工作点和训练协议被显式控制后，生物序列模型的头尾优势、跨条件迁移与拒识结论还剩下多少？哪些直观修复在严格对照下并不成立？**

贡献是一套可复核的基准与误差分层证据，不是 SOTA 机制。G1/G3/G4 的历史判决保留；M1a 是方法线的**止损终点**，不是又一次“重启”。

### 0.2 证据层级

| 标记 | 含义 | 可支持的写法 |
|---|---|---|
| **M-test** | strict3train 主集 146 实验；五折/三 seed test；预指定逐窗配对统计 | 仅当前验收协议与既定基线范围内的对照结论，不外推其他模型或 SOTA |
| **P-test** | 通过 foldfix 数据合同验收后的 RNA pilot 40 实验；多折/三种子 test；预注册配对统计 | 仅 foldfix 重跑并重新验收后可作 pilot 范围内的对照结论，不外推主集 |
| **P-test-legacy** | 旧加载器产生的 pilot/下游闭集结果 | 仅保留历史数值与统计痕迹；受 fold=-1 训练缺口影响，不支持当前科学主张 |
| **D-test** | 单折、单 seed、单划分或外部协议描述性 test | 现象与假设生成，不作稳定性或机制结论；旧闭集 D-test 同样标为 legacy |
| **M-desc** | 主集或外部数据上的描述性评测 | 明确样本与混杂，不能冒充多种子确认 |
| **V-gate** | validation-only 门控 | 只判断是否晋级，不报告 test 性能 |
| **H-protocol** | 旧训练协议的历史结果 | 只作协议对照，不与新协议混池 |
| **5S-test** | 蛋白统一新协议五划分、三 seed test | 新协议五划分范围内的结论 |

文中“显著”只在通过当前数据合同验收的 M-test/P-test/5S-test 中使用。旧 P-test-legacy 即使已有配对 bootstrap，也只能说历史表中的配对差达到统计阈值，不能升级为无泄漏泛化结论。单 seed、validation、在跑作业和计划均不进入确认性结论。

## 1. 自我反省：旧故事把“做过什么”误当成“为什么必须这样做”

旧链条“数据审计→强基线→证据路由→PU→OOD→蛋白”只是项目日程。它隐含了四次未被证据授权的跳跃：

1. 从“负例有偏”跳到“某种证据变量就是正确干预”；
2. 从“头尾方法不同”跳到“样本级路由应当有效”；
3. 从“存在假阴性候选”跳到“PU 风险应当改善召回”；
4. 从“跨条件映射不稳”跳到“同一不确定性分数应当可靠拒识”。

M1 又重复了同类错误：因为共享残差在概念上能连接这些现象，就把它写成故事的必然终点。M1a 未过门说明，概念连贯不是方法有效的证据；其旧闭集加载链缺口又限制了数值解释。新链条因此以**先审计测量合同，再排除替代解释**为推进原则：负例偏差要求把 id90 隔离从设计目标落实为可验收训练合同；foldfix 后的频率分层才允许进入强基线比较。旧路由/PU 只留历史止损记录，当前跨协议、OOD 和蛋白结果只承担外部有效性及边界检验，不再为旧方法补写机制。

## 2. 环环相扣的科学证据链

### S1｜实验过程与负例定义先决定“模型在学什么”

**现象。** 主集 fold0 的同一冻结 RNA-FM 探针，AUROC 从 neg1c 的 0.8901 降到 neg2 的 0.8188，差值 −0.0713。neg1c 的正负例 U 含量差为 −0.041，而 neg2 的转录本匹配显著缩小组成差异。neg1f 的 ±300 nt 排除 no-op 只影响少量邻域样本，不能解释整条 neg1c→neg2 降幅。

**对照。** 相同正例、冻结表征与探针，仅改变负例定义；neg1f 与修正后的 neg1c 作为实现伪影对照。

**run 与证据。** `E0-frozen-probe-20261122-095015-ZDLg6Y`（D-test，主集 fold0）；`E0-leakage-quant-20261122-102238-ZDLg6Y`（数据审计）。原始 `probe_mainfold0_summary.tsv` 回算：0.8188−0.8901=−0.0713。

**能排除。** 不能把 neg1c 的高分全部解释为 RBP 功能识别；也不能把全部轨间差异归因于 neg1f no-op。

**不能排除。** 负例的转录本/表达匹配仍不完全；残余序列组成、协议批次和基础模型预训练污染均可能影响分数。这里没有识别出唯一的生物因果变量。

**下一实验为何必要。** 若划分仍允许近重复跨折，即使换成 neg2，也可能用记忆替代功能泛化。因此下一步不是直接发明“证据状态”，而是先冻结同源隔离划分，再检验频率分层是否仍存在。

### S2｜strict3train 修复训练合同后，主集 BCE 相对簇去重 kNN 的优势通过验收

**E0 已证实事实。** 主集采用 id90 连通分量整折设计；2,147,319 个有 fold 归属窗口中，94.7403% 测试正例到训练正例的最近邻 `d_hom<0.7`。旧泄漏表报告宏平均 0.0225%，但其“train”实际包含 validation，且每正例被两条轨重复计数，不能解释为严格三折训练泄漏率。以上仅描述划分设计与序列相似性，不证明旧训练实现无泄漏。

**旧缺口与撤回。** 主集 2,168,739 个正例中有 21,420 个 `fold=-1`（0.9877%）；旧 E1 的布尔条件把这些 BASIC 外正例保留在每个 train 折。`ILF3_HepG2/fold0` 的实际训练数比只取 folds 2/3/4 多 303 个正例/轨，代码条件、数据表与旧 run 产物三者一致。因此旧 E1 主集继续撤回验收，旧主集与旧 pilot 不得支撑“BASIC 外样本不进 CV”“id90 跨折泄漏为零”或“闭集严格无泄漏”。

**旧 pilot 仅作历史记录。** 旧五折三种子的尾部 BCE−kNN ΔAUROC 为 neg1c +0.02515、neg2 +0.02789，历史 bootstrap 双侧 p=0.00019998；对应 ΔAUPRC 为 +0.03727、+0.04219。统计：`E1-paired-bootstrap-20261123-085242-ZDLg6Y`（**P-test-legacy**）。这些算术和配对统计可以回算，但不恢复为当前性能主张，也不与新主集混池。

**新主集验收结果。** 数据版本 `e0-v2-id90-strict3train-main` 显式只用三个训练折，fold=-1 不进入 train；146 实验的 15 modern、5 kNN 与 6 个后处理 run 全部完成。独立 AUDIT `E1-main-independent-audit-20261126-032635-ZDLg6Y`、合并 `E1-cv-prediction-combine-20261126-064253-ZDLg6Y`、CV `E1-cv-summary-20261126-065042-ZDLg6Y`、bootstrap `E1-paired-bootstrap-20261126-065044-ZDLg6Y`、低同源 `E1-stratified-analysis-20261126-104609-ZDLg6Y` 与独立回算 `E1-main-independent-recalculation-20261126-105611-ZDLg6Y` 均通过；26 行 run 清单和 `final_verification.json` 给出 accepted=true、old_npz_used=false。

### S3｜旧微调与骨干对照只保留历史现象，不被新主集自动恢复

**历史现象。** 旧 fold0/seed0 上，full 相对 frozen 在 neg2 头部 ΔAUROC=+0.01160、尾部 −0.03109；LoRA 同样头部获益、尾部受损。RiNALMo 的 BCE 尾部差在 neg1c 为 +0.01456，在 neg2 为 −0.00728。离散频率路由在 neg1c 尾部比最佳 kNN 高 +0.04646，但 neg2 尾部仅高 +0.00594。

**对照。** 同折同 seed 的 frozen/LoRA/full；RNA-FM/RiNALMo 的 BCE/kNN；只用 validation 按频率层选择候选的离散路由。这些对照来自旧闭集加载链，不能拼成“完整五折胜利”，也不能作为当前头尾权衡的最终证据。

**run 与证据。** 微调与三档对照：`E1-mode-comparison-20261123-124510-ZDLg6Y`（D-test-legacy）；骨干对照：`E1-mode-comparison-20261123-145602-ZDLg6Y`、`E1-mode-comparison-20261123-145603-ZDLg6Y`（D-test-legacy）；离散路由：`E1-discrete-router-20261123-150430-ZDLg6Y`（D-test-legacy）。

**能与不能排除。** 这些数值只说明旧协议下曾观察到非单调排序；fold=-1 训练缺口、单折单 seed、优化配方和收敛差异均未排除。因此“解冻更多参数必然改善尾部”等强假设并未获得合格的最终检验，离散路由现象也不证明样本级 `d_hom` 是正确路由变量。

**下一实验为何必要。** strict3train 已验收 frozen BCE 与簇去重 kNN 的主集比较，但模型容量、其他骨干和复杂路由仍需各自的新协议对照；不能沿用旧闭集优势，也不能把新 frozen/kNN 结果外推给这些未重跑方案。

### S4｜旧路由与 PU 负结果保留止损记录，但不冒充修复后闭集证据

#### S4a｜旧 `d_hom` 路由结果受同一加载器风险影响

**历史现象与对照。** 相对频率路由，evidence 的 neg1c 尾部 ΔAUROC=−0.00432（历史 p=0.0030），joint 为 −0.00365（历史 p=0.0106）；neg2 未显示稳定改善。对照使用同一 frozen 骨干、双轨、三种子、validation Platt 校准和逐窗配对 bootstrap。

**run 与证据。** `E2-paired-bootstrap-evidence-20261123-160559-ZDLg6Y`、`E2-paired-bootstrap-joint-20261123-160559-ZDLg6Y`（**P-test-legacy**）。首轮未校准尺度伪影已作废；fold=-1 训练缺口又使剩余结果不能承担“严格同协议下机制无效”的最终结论。

**证据边界。** 当前可执行判决仍是不恢复路由扩张；科学上只记录旧实现未显示增益，不据此否定所有连续状态、其他证据变量或所有路由结构。未运行的 E3 不得补写 oracle 或消融结论。

#### S4b｜天然假阴性是 E0/E4 审计事实，旧 nnPU 效果仍需合格协议

**审计事实与历史对照。** 源系负例与目标系同 RBP 位点重叠可定义天然假阴性候选；窗口包含重叠只是操作定义，不是精确交联中心真值。旧 nnPU−naive 的候选 ΔFNR 在 π=0.05、neg2 为 +0.02163（历史 p=0.0024），π=0.1/0.2 双轨均恶化；候选真值没有参与训练。

**run 与证据。** 候选审计 `E4-natural-truth-audit-20261123-164823-ZDLg6Y`；旧三种子统计 `E4-g3-bootstrap-20261123-172506-ZDLg6Y`（**P-test-legacy**）。前者支持“未检出≠阴性”的评测事实，后者受闭集训练合同缺口影响，不能作为最终方法效果证据。

**证据边界与下一步。** 当前 nnPU 先验与风险估计没有形成可验收的稳定改善，路线不因此重启；当前失败也不否定一切 PU 估计量。主故事不再用旧路由/PU 数值推进最终主张；strict3train 主集验收不自动恢复这些下游，必要影响评估完成前只保留历史对照。

### S5｜当前外部推进依赖已纠正的 PAR-CLIP 描述性结果，负例来源仍是核心分层变量

**当前现象。** 最新 patience20 跨协议三 seed 外部描述性结果中，9 RBP 宏 AUROC 为 eCLIP-neg1c **0.646192±0.002641**、eCLIP-neg2 **0.607869±0.002595**、PAR-CLIP 同协议 neg2 **0.655701±0.004951**；逐 RBP 仍高度异质。旧 fold0/seed0 跨细胞系结果与闭集 E1 共用加载链，现只保留历史痕迹，不再支撑当前跨条件主张。

**对照。** 跨协议固定 eCLIP 头，以 eCLIP validation 按 patience=20、min_delta=1e-4 选 epoch；PAR-CLIP 不参与训练或选参。三种外部负例切片分别报告：eCLIP neg1c、eCLIP neg2，以及其他 RBP 的 PAR-CLIP 位点经唯一基因匹配与目标位点 ±300 nt 排除构成的同协议 neg2。三者不混合计算，也不把切片间差值解释为模型提升。旧跨系 run `E1-cross-cell-modern-20261123-151445-ZDLg6Y`、`E1-cross-cell-knn-20261123-152246-ZDLg6Y`、`E1-mode-comparison-20261123-152722-ZDLg6Y` 均降为 D-test-legacy。

**run 与证据。** 当前跨协议 seed0/1/2 分别为 `E5-parclip-cross-protocol-contract-p20-20261125-065228-ZDLg6Y`、`E5-parclip-cross-protocol-contract-p20-20261125-065619-ZDLg6Y`、`E5-parclip-cross-protocol-contract-p20-20261125-065953-ZDLg6Y`（M-desc，9 RBP、三 seed、外部描述性）。

**能排除。** 当前结果不支持“一个 eCLIP 训练头可在不同 RBP、条件和协议间保持稳定判别力”的强假设；跨协议结果必须按 RBP 与负例定义分层呈现。

**不能排除。** eCLIP 两轨仍有协议、细胞环境和转录本组成混杂；PAR-CLIP 同协议 neg2 的其他 RBP 位点可能是目标 RBP 未观测位点，唯一基因筛选也改变覆盖和重复结构。三 seed 不是独立生物重复，不能作显著性或机制推断；两种负例来源的宏 AUROC 差不是协议校正的因果效应。

**历史状态撤回。** 本文此前引用的 30-epoch seed0 数字和 patience10 三 seed 工程状态均已被上述合同结果替代；patience10 不得称为满足20 epoch 停滞。历史 run 保留在 E5 报告中，不再支持当前数字。

**下一实验为何必要。** 分类分数在条件改变时不稳，并不自动意味着模型能识别“何时不知道”。必须在独立 OOD 任务上检查排序、工作点及指标语义，同时把描述性方向与逐 seed 不确定性分开。

### S6｜E5 三 seed 双轨显示 OOD 指标赢家冲突；蛋白三指标同向也不等于统一拒识

**E5 最终现象。** 12 个整 RBP 留出、双轨、三 seed 共 72 pair 已最终验收。deep-kNN 在两轨 AUROC-OOD/FPR95 宏均值上最佳，但 AURC 分别由 energy（neg1c）和 MSP（neg2）最佳；24 个 RBP×轨组中 23 个存在指标赢家冲突，只有 neg1c/IGF2BP1 由 energy 同时取得三项最佳。

|---|---|---:|---:|---:|
| neg1c | MSP | 0.505720 ± 0.000757 | 0.947533 ± 0.001007 | 0.155127 ± 0.000530 |
| neg1c | energy | 0.505720 ± 0.000757 | 0.947533 ± 0.001007 | 0.155127 ± 0.000530 |

| neg2 | energy | 0.451279 ± 0.005128 | 0.962582 ± 0.001344 | 0.473079 ± 0.000558 |

**对照与指标语义。** MSP、energy、deep-kNN 在同一 12 RBP×双轨×三 seed 上比较；AUROC-OOD 越高越好，FPR95/AURC 越低越好。MSP 与 energy 在二分类分数上单调等价，浮点尾差不构成实质性能差异。deep-kNN 的 AUROC 仅约 0.508、FPR95 约 0.946–0.947，且 AURC 明显更差，因此不能将其两项最佳写成可靠拒识。

**run 与证据。** 正式汇总 `E5-holdout-convergence-summary-20261126-112101-ZDLg6Y`：72 pair、216 行、missing=[]，独立三遍 verify 为 complete，48 次跨 seed 对齐通过。证据层级为 **pilot fold0 test、三 seed 描述性宏平均**；先在每个 seed×轨内对 12 RBP 宏平均，再对三 seed 求均值与样本 SD。未做 OOD bootstrap 或显著性检验，三 seed 是统计重复而非独立生物重复。最终报告：`E5_OOD/E5_整RBP留出三seed双轨最终报告_2026-11-26.md`。

**能与不能排除。** 当前结果否定“跨三项 OOD 指标一致的统一赢家”，不支持“拒识问题已解决”；但不能据此断言所有留出 RBP 都没有任何排序信号。AURC 还依赖分类错误，不是纯 OOD 可分性指标；两轨负例定义和类别先验不同，轨间差不是因果效应，三 seed SD 也不是生物重复置信区间。

**RNA 历史撤回。** 旧 E5 energy 的分数方向、AURC 累计方向与 FPR95 命名均存在错误，且旧闭集训练链还有 fold=-1 风险；旧 `E5-rbp-holdout-20261123-174134-ZDLg6Y` 数值与旧 68/72 阶段快照只保留历史，不参与最终结果。

**蛋白当前现象与对照。** 蛋白 OOD v2 修正后，MSP 与 energy 在 **5/5 split** 的 AUROC-OOD、标准 FPR95 和修正 AURC 三项描述性方向均优于 deep-kNN。蛋白使用 seed-ensemble 的 MSP/energy 与确定性 deep-kNN，在五 split Test-1/Test-2 pseudo-OOD 上按 `e6-ood-v2:fpr95=id_at_ood_tpr95;aurc=ascending_ood_score` 重算。三指标同向不升级为统一拒识或跨模态机制结论。

**蛋白 run 与边界。** OOD 离线重算 `E6-ood-metric-recompute-v2-20261125-072246-ZDLg6Y`，五划分汇总 `E6-five-split-summary-20261125-080318-ZDLg6Y`，独立语义回算 `E6-five-split-independent-verification-20261125-080348-ZDLg6Y`。Test-2 只是 pseudo-OOD；只有 AUROC-OOD 既有配对区间，没有新增 FPR95/AURC 逐 seed 区间或跨 split 显著性检验，不能证明逐 seed 稳定、跨蛋白泛化或真实未知 EC 发现。旧 FPR95/AURC、旧独立验证 `E6-five-split-independent-verification-20261125-045348-ZDLg6Y` 及“蛋白 MSP/energy 后两项更差”仅保留撤回痕迹。

### S7｜蛋白新协议 25/25 频率桶均为 BCE 优势，模态外推仍需独立证据

**现象。** 统一新协议五个 split、五个频率桶（含全部桶）共 **25/25 单元格**均为 BCE−deep-kNN Δmacro AUPRC>0，且每个单元格 95% CI 排除 0、双侧 p=0.00019998。`<10` 桶为 +0.264211 至 +0.277586，`10–29` 桶为 +0.330767 至 +0.362792；≥100 桶也为 +0.195413 至 +0.212319。当前蛋白故事是全频率桶一致的基线优势。

**对照。** 新协议固定 ESMC-300M 960 维冻结嵌入、BCE 线性头、三 seed、validation `<100` 标签宏 AUPRC 早停与 τ/阈值选择、10,000 次按 EC 标签配对 bootstrap。五划分最佳 epoch 均由 validation 曲线产生，未把 1000 epoch 故障保险当收敛证明。跨 split 只作等权描述性汇总，不 pooled 标签或构造跨 split 显著性。

**run 与证据。** 新协议 split_1–5：依次 `E6-grimm-frozen-baselines-20261124-085329-ZDLg6Y`、`E6-grimm-frozen-baselines-20261124-070400-ZDLg6Y`、`E6-grimm-frozen-baselines-20261124-104344-ZDLg6Y`、`E6-grimm-frozen-baselines-20261124-123513-ZDLg6Y`、`E6-grimm-frozen-baselines-20261124-171811-ZDLg6Y`；汇总 `E6-five-split-summary-20261125-080318-ZDLg6Y`、独立验证 `E6-five-split-independent-verification-20261125-080348-ZDLg6Y`（5S-test）。

**能排除。** 在当前 GRIMM EC_v2、冻结 ESMC-300M 和收敛协议下，检索在低频标签上必然占优的强假设被五划分全桶结果否定。

**不能排除。** 这不证明 BCE 在其他蛋白任务、骨干或训练协议中普遍更强，也不证明 RNA 与蛋白共享机制。蛋白截断、逐标签而非全局簇隔离、预训练污染和注释过程仍是限制；RNA 二分类与蛋白多标签任务不等价，25/25 方向一致也不是跨模态统一证据。

**历史撤回。** 旧 split_1 五 epoch 的“头部 BCE 强、尾部 kNN 强”仅保留为未收敛训练协议的历史对照（`E6-grimm-frozen-baselines-20261124-001704-ZDLg6Y`，H-protocol）；它与新协议不混池，不再用于主张头尾反转或纯 split 因果效应。

**下一实验为何必要。** 五划分完整性和 OOD v2 语义已验收，无需恢复路由或残差。后续若扩展，应检验其他蛋白任务/骨干与真实未知功能设定，以确定当前基线结论的外部边界。

### S8｜RNAcompete 五折证明基线排序依赖任务，RBP-OOD 相对优势不等于可靠迁移

**最终验收。** RNAcompete Ray2013 的 5 fold×3 seed×2 神经架构×2 轨共 **60/60 神经 eval**，以及 5 fold×2 轨的 **10/10 确定性 kNN** 全部完成。final verify `rnacompete-verify-final-all-all-f0-s0-2026-11-27T021412.509921Z0000-4099546` 与 summary `rnacompete-summarize-all-all-f0-s0-2026-11-27T024426.072076Z0000-4101649` 通过：70/70 eval、60 次 checkpoint CUDA replay、525 条 run 级指标与 45 行独立统计，selection 未使用 test。正式报告：`E1_强基线/RNAcompete_Ray2013_RNAFM五折最终报告_2026-11-27.md`。

**序列 ID90 tail。** 冻结 RNA-FM 640 维嵌入上，tail Spearman 为 **MLP 0.475605±0.002162 > linear 0.430202±0.002864 > kNN 0.352559±0.001378**；Pearson 分别为 0.420483±0.003787、0.358449±0.002265、0.261976±0.003714。该排序只覆盖既定三种基线，MSE 跨 fold/seed 变异很大，不作显著性或 SOTA 结论。

**整 RBP-OOD。** 实验宏 Spearman 反转为 **kNN 0.185360±0.027500 > MLP 0.111699±0.023439 > linear 0.098188±0.019112**。kNN 对所有目标 RBP 使用同一序列共识，并非任务特异预测；三者绝对相关性均弱，MSE 接近且离散度高，因此不能写可靠 OOD、统一优越或机制因果。

**科学推进。** 序列 tail 由 MLP 领先、整 RBP-OOD 由检索共识领先，直接支持**任务依赖的基线排序和多指标评价**，而非统一赢家。Fig. 6 `figures/Fig6_RNAcompete_Ray2013_five_fold_sequence_and_RBP_OOD` 已通过数值、矢量、DPI 和灰度验收并纳入主联系表；`manuscript/preprint_draft.pdf` 已完成 **15 页**。

**其他队列边界。** RiNALMo 正式 fold0/seed0 BCE 与 fold0 kNN 首批审计 `E1-rinalmo-independent-audit-20261127-023724-ZDLg6Y` 通过，但其余 15+5 矩阵仍在恢复；CAFA3 仅 7/36 partial；full chunk smoke 仅工程通过、fold0 在跑。这些状态不得进入完整强基线、CAFA 或微调性能结论。

## 3. M1a 是止损，不是重启

M1a 原配方在 pilot fold0、三 seed、validation-only 下，shared−independent 的 neg2 平均 Δtail AUPRC=−0.082107，低于 −0.02 退化门。对应 independent/shared run 为 `M1-function-independent-20261124-031552-ZDLg6Y` / `M1-function-shared-20261124-031552-ZDLg6Y`、`M1-function-independent-20261124-032747-ZDLg6Y` / `M1-function-shared-20261124-032747-ZDLg6Y`、`M1-function-independent-20261124-033805-ZDLg6Y` / `M1-function-shared-20261124-033805-ZDLg6Y`（V-gate-legacy）。降低学习率和 per-task 标准化两种修正也均未通过同一双轨门，详见 `M1_功能残差/M1a_共享代理门控报告_2026-11-24.md`。

**能排除的只是**当前共享头不能作为无代价的多任务起点；但 M1a 也使用旧 pilot 闭集链，fold=-1 缺口使其数值只能作 V-gate-legacy 止损记录。**不能声称**低秩残差已被证明无效，因为 M1b 根本没有运行；同样也不能声称它可能有效而继续扩张。预注册顺序明确规定 M1a 失败后停止，故 **M1b–M1f 禁止运行**。M1 在论文中至多作为带数据合同限制的 validation 历史负结果/路线纪律放入补充材料；主故事现由已验收的 strict3train 主集基准推进，而非方法重启。

## 4. 预印本题目与摘要骨架

### 4.1 推荐题目

**英文：** *Beyond Easy Negatives and Random Splits: Leakage-Controlled Benchmarks Reveal Conditional Trade-offs in Biological Sequence Models*

**中文：** 超越易负例与随机划分：泄漏受控基准揭示生物序列模型的条件化权衡

备选更保守题目：*A Leakage-Controlled Benchmark for Long-Tailed Prediction and Out-of-Distribution Rejection in Biological Sequences*。题目不使用“unified”“evidence-aware”“PU”或“proxy function gap”，避免把被否定或未识别的方法写回贡献。

### 4.2 摘要骨架（当前证据版，非投稿终稿）

- **背景：** 生物序列基准同时受同源冗余、构造负例和条件特异标签影响；若只报告随机划分总体指标，模型比较可能混合记忆、技术偏差与真实泛化。
- **方法与合同修复：** 以 id90 连通分量五折、neg1c/neg2 双轨与频率/同源/跨条件切片控制测量。旧加载器曾把 fold=-1 正例带入每个 train 折；strict3train 新版本显式只用三个训练折并完成独立验收，旧 E1 主集继续撤回，旧 pilot 及受影响下游不进入当前性能主张。
- **E0 测量事实：** 主集 fold0 冻结探针在两种负例轨上的 AUROC 为 0.8901/0.8188（Δ=−0.0713），说明负例定义显著改变可学难度；这不是唯一因果分解。
- **E1 主集：** 146 实验五折三 seed 中，frozen RNA-FM BCE 相对簇去重余弦 kNN 的尾部 pooled ΔAUROC/ΔAUPRC 为 neg1c +0.031365/+0.043649、neg2 +0.024114/+0.034854；12 个切片的 95% CI 均排除 0、双侧校正 p 均为 0.00019998。低同源只作三 seed 描述性；结果不是 SOTA 或完整最强基线胜利。
- **外部有效性：** 已纠正并验收的 patience20 三 seed PAR-CLIP 结果显示明显 RBP 与负例来源异质性，且仅为 9 RBP 外部描述性。
- **RNAcompete：** 五折 60/60+10/10 已验收；序列 tail Spearman 为 MLP 0.475605 > linear 0.430202 > kNN 0.352559，RBP-OOD 则为 kNN 0.185360 > MLP 0.111699 > linear 0.098188，但绝对相关性均弱，支持任务依赖而非统一赢家。
- **RNA OOD：** E5 72/72 最终结果中，deep-kNN 两轨 AUROC-OOD/FPR95 最佳，但 AUROC 约 0.508、FPR95 约 0.946–0.947；AURC 分别由 energy/MSP 最佳，23/24 组有指标冲突。该三 seed 描述性结果不支持可靠统一拒识。
- **蛋白分类与 OOD：** 统一新协议五划分的 25/25 频率桶均为 BCE>kNN；OOD v2 的 MSP/energy 三指标方向虽均优于 deep-kNN，但仅限 seed-ensemble pseudo-OOD 描述，不能替代逐 seed 区间或真实未知功能验证。
- **结论：** 当前证据支持严格三折主集既定基线比较、数据审计、E5 指标冲突、已纠正外部/OOD 切片与蛋白协议边界，不支持统一证据路由、PU、残差机制、可靠统一拒识或 SOTA。
- **终稿待补：** 其他骨干、微调与机制结论不被 E1 frozen/kNN 结果自动覆盖；E5 仍需明确三 seed 描述性、无 OOD bootstrap 和非独立生物重复边界。
