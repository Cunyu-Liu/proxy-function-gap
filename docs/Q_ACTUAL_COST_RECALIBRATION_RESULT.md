## 验证

- 聚焦测试与全量测试通过；最终全量为 265 项。
- Q 的三轮验证均在 CUDA 上重新计算 raw/calibrated 概率、OOF 阈值和 log loss。
- 三轮独立评测/汇总通过，逐轮 JSON 字节一致；outer evaluator 同时完成三轮独立标签对账。
- `production-grid --actual-cost-budget 13` 真实 CUDA CLI smoke 产出 5 条记录、实际成本 13，并正确标记截断；alpha0 WSC 的 verifier 成本为 0。

## 结论解释

- calibration 上 FP-REJ 的 V+Q regret 为 3.4041，高于 V-only 的 3.2983，覆盖率降至 0.9375；Q log loss 改善没有转化为选择 regret 改善。
- 两类 outer 的 Q 均未触发拒选，因此 V+Q 与 V-only regret 完全相同，却增加 Q head 和全池 Q 特征成本。outer designed 中 FP-REJ 相对 BoN 的差值为 +0.3432，未显示优势；outer random 的 -0.0552 差值区间跨 0，且只有三个完整池，不能声称改善。
- FP-TILT 的全支持集成本明显超出共同主预算：designed 为 192 CNN+256 V，random 为 768 CNN+1024 V，不能与 48-CNN 预算内策略作等成本优越性解释。
- outer 的差值和区间只用于探索性协议敏感性分析，不构成新盲测证据，也不据此调整 Q、V 或选择器。
