## 1. 结论

在严格隔离的 GFP ≥5 阶永久 test 上，**1–2 阶监督拟合确实转化为本批高阶固定池中的等预算选择收益**。CNN 与简单加性岭回归在 B={1,4,16,64} 下均有负的 `BoN regret−RandomN regret`，且 16 池 bootstrap 的 95% 区间均不跨 0。五个 CNN 种子在每个预算上的平均差值也全部为负，因此结果不是单一训练种子驱动。

但这不等于高阶点态预测普遍可靠：CNN 的总体 Spearman 为 0.434，5 阶为 0.582，8 阶降至 0.076，9 阶为 −0.020。加性模型在四个预算上的 BoN regret 都低于 CNN，说明**简单加性基线已足够获得本任务的选择收益，不能把收益归因于复杂 CNN 或高阶相互作用建模**。

结论仅适用于 Sarkisyan 2016 已测局部景观中冻结的 16 个池，不覆盖完整高阶组合空间，也不证明优化轨迹动力学或普遍跨场景阳性。

## 2. 数据与角色隔离

源文件为 ProteinGym v1.3 的 `GFP_AEQVI_Sarkisyan_2016.csv`，14,347,114 bytes，SHA-256：

`05b97d36a23363331b271edc56f1496b9a539109fd006e65532f91e9903a0838`

实际读取 51,714 条唯一变异，完整序列均长 238 aa，标签为实验派生的 log 尺度亮度 `DMS_score`，高分更优。GFP 亮度不是纯蛋白表达量。

| 角色 | 数量 | 处理 |
|---|---:|---|
| train，1–2 阶 | 7,046 | 163 个突变位点；仅这些标签用于拟合 |
| dev，1–2 阶 | 1,410 | 70 个互斥位点；仅用于容量、正则与早停选择 |
| 低阶位点边界排除 | 5,405 | 跨 train/dev 位点，保留清单，不训练、不调参 |
| 3–4 阶压力区 | 21,723 | 完全不用于本轮训练或调参 |
| ≥5 阶合格 outer | 16,130 | 与低阶最小可能 Hamming=3 |
| 永久 test 固定池 | 16,000 | 16 个互不重叠的 N=1,000 池 |
| 未使用高阶余量 | 130 | 保留清单，不进入评价 |

train/dev 位点互斥，exact/H1 跨角色为 0。**交付核验更正：train/dev 的最小 Hamming 是 2，不是预评价 raw-gate 字段误写的 3。** 不同位点的两个单突变可以相距 2；这不影响低阶到 ≥5 阶 test 的最小距离 3，也未改变任何拆分、预测或结果。更正见 `verification/posthoc_hamming_correction.json`。

拆分收紧发生在任何训练和 test 揭盲之前：最初低阶 H1 连通图几乎整体连通，整组哈希仅留下 19 条 dev，遂废弃；随后采用位点阻断，并因 20% 位点仅产生 762 条 dev 而预冻结为 70/30 位点划分。上述调整均由样本量与隔离门控触发，与 outer 标签或效果无关。

## 3. 模型与等预算评价

- CNN：氨基酸 one-hot，两层 1D convolution，均值/最大池化与回归头；grid 为 channels {32,64}×kernel {5,9}，5 seeds {11,23,37,51,73}。
- 全部 20 个 run 在 NVIDIA RTX 5090、PyTorch 2.7.1+cu128 上真实训练，均记录非零 CUDA 显存分配；峰值约 273–445 MB。
- dev 选中 `channels=32, kernel=9`，五种子平均 dev MAE=0.3507、Spearman=0.2326。最终高阶预测为五种子等权平均。
- 加性基线：位置特异氨基酸 one-hot + Ridge，dev 选中 alpha=1。
- 三份高阶预测、5 个选中 checkpoint、配置和执行代码先哈希冻结，再由 Evaluator 启动唯一一次 test 评价。
- 每个池的 BoN 与 RandomN 使用相同 N=1,000 候选和相同 B；RandomN 为 64 个固定随机重复的平均。regret 为池内真实最大亮度减去所选集合中的最大真实亮度。
- 主差值定义为 **BoN−RandomN，负值有利于 proxy**。区间只重抽样 16 个固定池，不是湿实验重复误差区间。

## 7. 三轮核验

1. **原始与门控核验：PASS。** 固定 SHA-256、51,714 行、全阶数分布、16,130 条高阶、16×1000 池、低阶/test 最小距离 3；train/dev 位点零重叠。预评价低阶 dev 不足方案被废弃；train/dev 最小距离字段的交付更正单独保留。
2. **独立科学重算：PASS。** 不导入生产模块，重新读取原始标签和冻结预测，独立实现 tie-aware 排序、64 个 RandomN 重复、MAE 与平均并列秩 Spearman；128/128 个方法×池×预算配对一致，最大绝对差 0，主均值与点态指标一致。
3. **本地脱敏交付核验：PASS。** 文件哈希、128 个逐池均值、8 个主区间、一次评价标记、20 个 CUDA run、回顾性措辞和本地无序列级 CSV/NPY/NPZ/PT 文件均由 `code/verify_delivery.py` 检查；结果见 `verification/round3_delivery.json`。

远端两次 HTTPS 证书链失败和本地首次 300 秒下载中止未隐藏；最终文件通过正常本地 TLS 下载、断点续传和固定 SHA-256 验证，没有关闭证书校验。

## 8. 可允许与不可允许的表述

可以写：在 GFP 公开历史数据的严格阶数隔离固定池上，低阶监督模型和加性基线均显示等预算高阶选择收益，但点态相关性随突变阶数明显下降。

不能写：该结果证明 decision-focused 方法普遍有效、复杂 CNN 优于加性模型、完整高阶组合空间可可靠预测、已开展新盲测或湿实验验证，或已证明优化压力轨迹动力学。

本地目录只含代码、配置、聚合结果、池级结果和核验日志；原始序列、逐变体标签、预测数组和 checkpoint 保留在远端完整产物中。
