# E0 冻结协议与公式假设

## 1. 科学边界

E0 仅验证固定完整序列候选池上的算法正确性和调用计数。所有 `truth` 都是程序构造的合成数值，不是实验标签；结果不得解释为生物功能、真实 regret 优势或 GPU 训练结论。一期没有前缀生成、前缀 V、MDM、真实数据或模型训练。

## 2. 候选池与约束

候选池为 \(C=\{x_1,\ldots,x_M\}\)，基础提议分布为 \(P_i\)，满足 \(P_i\geq0\)、\(\sum_iP_i=1\)。UTR 长度、GC、uAUG 和 poly-U 约束形成硬掩码 \(m_i\in\{0,1\}\)。实际提议分布为

\[
\tilde P_i=\frac{m_iP_i}{\sum_jm_jP_j}.
\]

不可行候选不会被提议或计分。若可行概率质量为零则停止并报错。E0 不实现全长 CDS 阅读框约束。

## 3. 六种选择器

所有随机提议均从 \(\tilde P\) **有放回**抽取，与原 VGSC 的 i.i.d. 提议一致。\(N\) 是单次选择的提议上限。V-only 使用 \(w_i=V_i^\alpha\)，joint 使用 \(w_i=(V_i\hat Q)^\alpha\)，其中 \(\alpha\geq0\)、\(V_i,\hat Q\in[0,1]\)。

- **random**：从 \(\tilde P\) 抽一个候选，不调用 proxy/V/Q。
- **BoN**：抽满 \(N\) 个，逐次调用 proxy，返回 proxy 最大者。proxy 不隐式进入其他策略，除非调用方在外部用它定义 \(P\)。
- **WSC**：抽满 \(N\) 个，事后按 \(V_i^\alpha\) 对已抽提议加权并随机选一个；不使用 Q。它是 post-hoc 加权，不改变提议分布。若缓存权重全为零，同样明确采用缓存提议上的均匀分布。
- **greedy**：抽满 \(N\) 个，返回 \((V_i\hat Q)^\alpha\) 最大者；Q 是池级标量，每次选择计一次调用。当 \(\alpha>0\) 时，共同的正 Q 因子不改变排序，Q=0 时所有候选平分并保留最早提议，因此 greedy 不能用于证明 Q 的增量。
- **V-only**：逐个提议并按 \(V_i^\alpha\) 接受，首次接受即停止；最多 \(N\) 个。全部拒绝时在缓存提议中按 \(w/(1-w)\) 回退选择。
- **joint**：与 V-only 相同，但 \(w=(V_i\hat Q)^\alpha\)，Q 每次选择计一次调用。

平分保留最早提议。全部拒绝且所有回退权重均为零时，原公式出现 \(0/0\)；E0 明确采用缓存提议上的均匀分布，不读取其他分数或真值。

## 4. 精确倾斜与 Q 的歧义

解析参考分布定义为

\[
T_i=\frac{\tilde P_i w_i}{\sum_j\tilde P_jw_j}.
\]

由于本方案的 \(\hat Q=\hat Q_t\) 是池级标量，精确 joint 倾斜中 \(\hat Q^\alpha\) 在归一化时约掉，因此 **精确 V-only 与精确 joint 完全相同**（在两者均有定义时）。有限 \(N\) 的拒绝采样中，Q 会改变绝对接受率及回退概率，所以离散算法可能不同；这种差异不是 Q 具有真实风险预测增量的证据，必须留待 E3 判定。若所有正提议质量候选的倾斜权重都为零，解析分布无定义并报错。

## 5. 预算口径

`proposals`、`proxy_calls`、`verifier_calls`、`qhat_calls` 分别记录，不合成含义不清的单一“模型调用数”。每次提议计分都收费，重复序列不缓存；这避免把缓存命中伪装成零成本。BoN/WSC/greedy 的提议数固定为 N，V-only/joint 可提前接受而小于 N，random 只提议一次。相同 N 只是相同上限，不代表实际计算量相同；任何后续比较必须报告实际分模型调用数，不能仅凭相同 N 宣称公平。

## 6. 合成误差与 regret

合成案例冻结为

\[
P_i^{proxy}=Y_i^{synthetic}+b_i+\epsilon_i,\qquad
\epsilon_i\sim\mathcal N(0,0.01^2),
\]

其中高 proxy 偏差 \(b_i\) 施加在预先指定的 decoy 上，V 是另行构造的可靠性分，不由选择器读取 Y。合成真值只在选择完成后进入评分函数：

\[
R(\pi)=\max_{i:m_i=1}Y_i^{synthetic}-Y_{i_\pi}^{synthetic}.
\]

该数值仅用于触发已知正确答案的单测，不是科学效果量。

## 7. E0 门禁

1. 公式和退化规则已冻结，接口输入校验完整。
2. 完整 pytest 无失败、无 xfail；解析公式由独立参考计算核对。
3. 预算计数覆盖重复提议、提前停止、上限超限、约束屏蔽和各模型调用维度。
4. 独立代码审查确认无真值泄漏、无前缀生成、无真实数据、无 GPU/训练路径。
5. 同一冻结配置两次端到端运行 JSON 完全一致。

未全部满足则 E0 不通过，不进入 E1。通过也只表示软件正确性门禁通过。
