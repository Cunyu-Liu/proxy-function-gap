## 1. Cao 2021（zzz2010/5UTR_Optimizer）

### 1.1 来源与许可
- 仓库 https://github.com/zzz2010/5UTR_Optimizer （master，17MB）；对应 Cao et al. bioRxiv 2020.03.24.006486 → Nat Commun 2021 12:4138（DOI 10.1038/s41467-021-24436-7）。LICENSE 存在（MIT 风格，待人工确认）。
- 远端集群可访问 GitHub API（200）与 raw.githubusercontent（200），但 raw 带宽实测 ~10KB/s。

### 1.2 终点语义修正（关键审计发现）
P3 检索把 Cao 描述为"合成库**蛋白产量**（报告基因表达）"。实际仓库 readily-available 数据是：
- `data/df_counts_and_len.TE_sorted.{HEK_Andrev2015,Muscle,pc3}.with_annot.txt`：**内源 5′UTR 的翻译效率 TE**（ribo-seq/RNA-seq rpkm 派生），来自公开 PC3/HEK/muscle 数据集。列：riboseq_counts, rnaseq_counts, rpkm_riboseq, rpkm_rnaseq, **te**, norm_riboseq, norm_rnaseq, ensembl_tx_id, external_gene_id, transcript_biotype。
- 注释表**无序列列**；序列在 `data/gencode_v17_5utr_15bpcds.fa`（16MB，内源 5′UTR+15bp CDS），需按转录本 ID 拼接。
- 论文真正的**合成库蛋白产量**新实验数据在 GSE176581 raw FASTQ，需重处理，非本轮可零样本获取。

**结论**：可零样本评价的面是"内源 5′UTR TE"，相对 MRL 训练 proxy 属**跨研究 + 跨终点 + 跨分布（内源 vs 随机合成）**，主张必须限定；不能写成"蛋白产量"。P3 终点描述据此修正。

### 1.3 门禁判定
- 文件 14–16MB，集群→raw 带宽 ~10KB/s（实测 140s 仅下载 1.4MB/14MB），可靠下载本轮不现实。
- 即使下载，需 fasta 拼接 + 泄漏审计 + 冻结协议 + GPU 推理，工作量超出本轮有界尝试。
- **判定：访问受限 + 终点跨_endpoint_，未执行评价。** 列为合格候选（终点修正后），未来工作。

## 2. Ogden 2019（GSE139657 AAV2 肝 tropism）

- P3 定位 LiverTropism CSV 752KB（小文件，理论上可下载）；in vivo 小鼠肝脏 tropism，高价值终点。
- 本轮尝试 `https://www.ncbi.nlm.nih.gov/geo/download/?acc=GSE139657&format=file` 返回 **0 字节**（NCBI 访问被拦，与 P3 记录的 reCAPTCHA 一致）。

- **判定：NCBI 访问受限，未执行评价。** 列为合格候选，未来工作（需新训蛋白 proxy 或验证 AAV9→AAV2 表示兼容）。
