> **纠错记录**：此前版本的 FPR95 实为 OOD TPR@ID-FPR5，AURC 按 OOD 分数降序累计，二者定义均错误；旧数值、风险覆盖表及“MSP/energy 后两项不占优”的结论全部作废。本版已从保存的逐样本分数重算，并将定义版本、分数 SHA256、合成反例和独立语义回算纳入 accepted 门控。分类结果不重训、不改变。

## 1. 验收判决

- 五个官方 split 均已完成新协议：每折 seed 0/1/2、960 维冻结嵌入、validation 早停、validation 选择 τ 与 Fmax 阈值、10,000 次 bootstrap。没有缺失或未验收 split。
- **旧 split_1 五 epoch 结果中的“头部 BCE 强、尾部 kNN 强”与 split_2 的头尾排序反转，在统一收敛协议下不成立。** 新协议 split_1 与 split_2 一样，所有频率桶均为 BCE−kNN > 0；该方向在 split_3–5 也全部成立，且每折每桶的 95% CI 都排除 0。
- 因而，split_2 的“BCE 全桶占优”在五划分中方向一致；旧 split_1 结果只保留为未收敛训练协议的历史对照，不与本报告混报。结果差异与训练协议改变相伴，但本验收不做进一步因果归因。
- 修正后，MSP/energy 在五折的 AUROC-OOD、FPR95、AURC 描述性方向均优于 deep-kNN；旧“后两项不占优”是错误实现造成的。该方向仅限当前 seed-ensemble pseudo-OOD 分数，不附新的 FPR95/AURC 置信区间，不证明逐 seed 稳定或真实未知 EC 发现。

本报告是**五划分 Test-1/Test-2 冻结协议结果**。逐 split 的 EC 标签 bootstrap 给出折内不确定性；跨 split 仅作等权描述性均值、样本 SD、范围与方向计数，**不 pooled 蛋白或标签，不构造伪增样本量的跨 split 显著性检验**。

- 编码器为官方 ESMC-300M，参数冻结，真实氨基酸位置均值池化。五折 train/validation/test1/test2 共 20 个嵌入数组均为 960 维、全部有限，数组行数与对应 TSV 一致，Entry 顺序完全对齐。
- `per_label_metrics.tsv` 的 EC 标签在 seed 0/1/2 与 deterministic kNN 间完全对齐；训练频次和频率桶与 train 标签计数一致。模型标签为 `frozen_bce_la` 与 `deep_knn`，汇总未再把 BCE 模型误过滤为空。
- 每个 seed 的 history 均独立重放 `min_delta=1e-4` 的 checkpoint 规则；记录的最佳 epoch 与重放一致。所有 last epoch 都恰为 best epoch+20，符合 `patience=20` 早停。最佳 epoch 为 71–112，未把 1000 epoch 故障保险上限当作收敛证明。
- τ 网格固定为 `{0,0.5,1}`，按 validation `<100` 标签 macro AUPRC 选择一个跨 seed 共用值；每折模型记录的 τ 与 validation 最优值一致。Fmax 阈值由 validation 逐 seed/模型选择，未读取 test 进行选择。

## 5. Test-1 vs Test-2 pseudo-OOD：修正定义后的三指标

定义版本为 `e6-ood-v2:fpr95=id_at_ood_tpr95;aurc=ascending_ood_score`。OOD 分数越大越未知：

- **FPR95**：取 OOD 分数的 5% 分位阈值（linear），计算 ID 分数大于等于该阈值的比例，即 OOD TPR=95% 工作点的 ID 假阳性率。
- **AURC**：按 OOD 分数升序，从最像 ID 的样本开始扩大 coverage，累计已接纳样本中的 OOD 比例，再用梯形法积分。
- 旧量只保留为显式命名的 `ood_tpr_at_known_fpr5` 审计字段，不再占用 FPR95 列。AUROC-OOD 不受本次纠错影响。MSP/energy 为三种子分数先做 seed-ensemble 平均再计算指标，deep-kNN 为确定性分数。

### 审计数值的独立复现与并列处理

本报告不是照抄审计表：远端重算直接读取 15 个已哈希 float32 分数文件，独立 verify 使用另一套公式再次回算；本地还在 NumPy 2.0.2 下从同步原数组独立执行相同数学定义，复现了 `CODE-STAT-AUDIT-20261125-ZDLg6Y` 简表中的所有 FPR95/AURC 六位小数及方向。

远端产物使用 NumPy 2.2.6、`np.argsort(..., kind="quicksort")` 和 linear 分位法。部分方法有大量并列分数，NumPy 版本的并列次序会使少数 AURC 末位不同，因此本表以远端哈希固定产物为准，审计简表以本地独立复现为准；方向不变。版本、排序规则、分数 dtype 和 SHA256 均已写入产物。该末位敏感性不得隐藏，也不改变上述描述性方向。

## 6. 蛋白结论与跨模态边界

可以写入论文的限定结论：

- 在 GRIMM EC_v2 五官方划分、frozen ESMC-300M、validation 收敛训练协议下，BCE 线性头相对 deep-kNN 的 macro AUPRC 优势覆盖所有频率桶，并在五折方向一致。
- 旧 split_1 五 epoch 的头尾反转没有在新协议五划分中复现，不能再作为“蛋白尾部检索必然更强”或“跨模态方向必然相反”的证据。
- 在当前 seed-ensemble pseudo-OOD 分数上，MSP/energy 的 AUROC-OOD、FPR95、AURC 五折描述性方向均优于 deep-kNN；这是纠错后的基准观察，不是逐 seed、跨蛋白或真实未知功能发现的机制结论。

不得外推：

- 不把当前结果写成统一跨模态机制、RNA 结论的反向证明、SOTA 或完整最强基线之上的方法胜利。
- Test-2 只是 pseudo-OOD，不能宣称未知 EC 功能发现；已知标签重叠、逐标签簇隔离、重复序列、截断与预训练污染限制继续有效。
- 当前没有 MMseqs2 实测 identity 分桶，余弦相似度不称作 sequence identity。
- 五划分描述统计不表示五个独立生物重复的 pooled 推断，也不恢复已停止的 M1b–M1f 或任何残差机制线。
